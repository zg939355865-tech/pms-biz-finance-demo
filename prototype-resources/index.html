必须遵守

  1. 01优先匹配页面样例，再选择组件，不从空白页面自由发挥。
  2. 02组件必须存在于资源 Manifest 或 PMS Schema 注册表。
  3. 03颜色、间距、圆角、字号和阴影只使用项目 Token。
  4. 04列表、新增、编辑、详情优先共用一个 HTML。
  5. 05操作列只保留删除；编号链接按流程状态进入编辑或只读详情。
  6. 06每个交互必须包含加载、成功、失败、空数据和禁用状态。
