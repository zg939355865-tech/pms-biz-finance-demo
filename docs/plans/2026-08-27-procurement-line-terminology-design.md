# 采购行术语统一设计

## 范围

- 覆盖采购管理菜单下实际出现订单/入库来源行的采购订单、采购入库、采购收票页面及弹窗。
- 采购申请的采购明细、支出合同的标的明细等其他业务对象保持原名称。

## 术语规则

- 采购订单自身及以采购订单为来源的数据粒度统一称“订单行”。
- 采购入库自身及以采购入库为来源的数据粒度统一称“入库行”。
- 采购入库主表来源行随类型动态显示：蓝字为“订单行”，红字为“入库行”。
- 字段编码、数据源、选择和回填逻辑、上下游追溯关系不变，仅调整用户可见文案及同步说明。

## 验收

- 蓝图、Schema、生成 HTML 与聚焦回归断言一致。
- 页面和弹窗不再显示“订单明细行”“入库明细行”“入库单明细行”或无法辨识业务对象的“明细行”。
