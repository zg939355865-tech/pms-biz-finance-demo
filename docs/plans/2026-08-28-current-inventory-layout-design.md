# 即时物资布局优化设计

## 设计结论

- 删除原累计采购汇总功能合同、菜单入口和页面产物。采购名称当前为人工填写，缺少稳定物资主数据编码，不具备可靠合并统计条件。
- “即时物资”继续作为系统只读库存结存视图，保留采购类别、采购名称、规格、单位、库存余量、库存地点、库位七个字段。
- 查询区采用固定宽度的左对齐标签，首个查询标签与列表首列文字使用相同的 24px 卡片内边距。
- 列宽合计压缩到 944px：采购名称、规格和库存地点优先获得展示空间；单位、数量保持紧凑；数量右对齐，其他业务字段左对齐。
- 库位查询使用下拉框；“显示零库存”复选框不显示额外字段标签，默认不勾选并排除库存余量为 0 的记录。
- 页面在 1440px、2048px 及菜单 iframe 中不得出现页面级横向溢出；常规桌面宽度下不显示不必要的表格横向滚动条。

## 验证重点

- 菜单、蓝图、Schema、HTML 和专项回归中不再存在原累计采购汇总功能入口或标识。
- 查询区首个可见标签与表头、首列数据左边界像素差不超过 1px。
- 七列表头与数据列宽一致，数量列右对齐，名称、规格、地点和库位无异常挤压。
- 固定 5 条/页，无页容量下拉、无新增、编辑、删除、审核和详情操作。
- 默认查询排除零库存，勾选“显示零库存”后恢复零库存记录。
