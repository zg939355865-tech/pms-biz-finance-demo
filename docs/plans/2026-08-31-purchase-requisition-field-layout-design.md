# 采购申请字段与页签优化设计

## 设计结论

- 详情保留“基础信息、附件”两个页签；基础信息页签先展示主表表单，再展示标题为“申请明细”的可编辑表。
- 主表字段严格按用户指定顺序展示；申请人、申请时间、所属公司同时承载公共审计字段，避免重复出现创建人、创建时间等同义字段。
- 所属项目改为必填下拉，新增时保留“通用项目”默认值；申请用途按指定六项枚举实现。
- 申请明细预估金额按“数量 × 预估单价”实时计算，基础信息预估总金额汇总全部明细行预估金额；删除明细表下方的重复汇总卡片。
- 预估金额右侧增加备注；申请明细操作列仅保留删除并固定在表格最右侧，表格横向滚动时保持可见。
- 申请部门由当前申请人所属部门自动带出并只读展示；申请人变化时同步更新部门。
- 列表和查询按用户指定字段及顺序收敛，查询项目使用输入框、申请部门使用下拉框；列表仍保留公共选择列、固定操作列及每页 5 条分页。

## 验证范围

- 蓝图、正式 Schema、有效 Schema、生成 HTML 和采购申请聚焦回归断言同步更新。
- 验证字段顺序、查询控件类型、必填标识、用途选项、通用项目默认值、申请人部门联动、金额计算、明细列顺序、固定删除列及重复汇总删除。
