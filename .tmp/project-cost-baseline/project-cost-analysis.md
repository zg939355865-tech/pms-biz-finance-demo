## 2. 需求理解与 AI 假设

### 2.1 用户明确要求

1. 将“项目成本分析”菜单及页面标题调整为“项目成本”。
2. 查询条件仅保留会计期间范围、项目、成本类型；会计期间范围默认当前会计期间至当前会计期间，允许清空不选，项目使用下拉框。
3. “月度成本趋势”调整为“会计月成本趋势”。
4. 项目成本汇总去除说明，按年度-会计期间、项目及六类成本展示，并对成本总计及六类成本增加合计行。
5. 去除项目成本指标卡和成本类别构成图，列表页主体仅保留查询条件、会计月成本趋势图和项目成本汇总列表。
6. 查询区缩小左侧留白；“项目”下拉选项展示项目编码和项目名称。
7. 查询、趋势图和列表之间采用统一的标准间距。
8. 用户已要求基于本蓝图生成 Schema、HTML，并接入菜单路由。

### 2.2 AI 补充内容与假设

1. 页面定位为只读分析页，不新增、编辑、删除、审核或反审核成本来源单据。
2. 列表以“年度 + 会计期间 + 项目”为展示粒度；底层成本事实仍保留所属公司核算边界，不跨核算主体合并可记账金额。
3. 项目成本来源暂按采购服务履约、物资消耗、费用报销、人工、折旧摊销、间接费用分摊和成本调整七类展示。
4. **AI 假设：**分析页展示查询条件、会计月成本趋势及项目列表，点击项目编码后从右侧打开只读明细抽屉。
5. **AI 假设：**项目成本和部门成本基于同一成本事实明细，项目页按项目汇总，部门页按成本归集部门汇总，不生成两套成本数据。
6. **AI 假设：**页面同时展示“已归集成本”和“数据完整性”；人工、费用、折旧、分摊等来源未完成时，仍可展示当前已归集金额，但不得标记为完整真实成本。
7. 成本确认时点、库存计价、税额处理、人工成本、折旧回写、间接费用分摊、跨期和多币种规则会影响真实业务结果，均列入第 15 章待确认项，蓝图不将其固化为已确认会计规则。

## 3. 业务目标与范围

### 3.1 业务目标

统一展示项目在指定期间内的成本规模、成本构成、变化趋势、来源完整性和业务单据依据，解决采购、领料、费用、人工、折旧及分摊成本分散、项目成本依赖线下汇总且难以追溯的问题。

### 3.2 主要使用人员

- 公司管理层：查看项目成本规模、结构和异常项目。
- 项目经理：查看本项目成本构成、发生期间及来源单据。
- 财务及成本会计：检查成本归集完整性、跨期数据和业务财务差异。
- 部门负责人：查看本部门承担成本对项目成本的贡献。

### 3.3 本次包含

- 按会计期间范围、项目和成本类型查询；会计期间范围默认当前会计期间至当前会计期间，并允许清空不选。
- 展示会计月成本趋势。
- 按年度-会计期间及项目展示成本总计、服务采购、物资消耗、费用报销、人工成本、折旧摊销和间接费用。
- 点击项目编码查看该项目的成本摘要和统一成本来源明细。
- 从成本来源明细穿透至现有业务单据；尚未建设或未接入的数据源显示明确状态，不以 0 替代未知值。

### 3.4 本次不包含

- 成本调整单的新增、审核和反审核。
- 库存计价、人工成本计算、折旧计算和间接费用分摊规则配置。
- 月末结账、反结账、成本重算和财务凭证生成。
- 项目收入、毛利、回款、预算执行和利润排名；本页只分析成本。
- 修改项目、部门、采购、物资、费用、人工、固定资产和凭证数据。

### 3.5 业务链路

```text
项目立项
  -> 已审核服务结算 / 已审核物资出库 / 已审核费用 / 月度人工 / 用友折旧 / 间接费用分摊 / 已审核成本调整
  -> 成本事实明细
  -> 按所属公司 + 会计期间 + 项目汇总
  -> 项目成本
  -> 与用友成本、存货、资产及凭证结果对账
```

## 5. 页面区域

### 5.1 列表视图

1. 页面头：显示标题“项目成本”，不提供新增或批量业务操作。
2. 查询区域：按会计期间范围、项目、成本类型依次展示；会计期间范围使用月份范围控件，起止值默认当前会计期间，支持清空；项目使用下拉框并展示项目编码和项目名称。
3. 图表区域：仅展示会计月成本趋势；无完整取数时显示缺失说明，不补零形成虚假趋势。
5. 项目成本汇总列表：去除标题下方说明，按年度-会计期间和项目展示成本总计及六类成本；项目编码是唯一明细入口，底部合计金额列。
6. 分页区域：固定每页 5 条，不提供页容量选择，不产生业务页面内部纵向滚动条。

### 5.2 详情视图

1. 项目摘要：展示所属公司、项目编码、项目名称、项目类型、项目状态、项目经理、成本归集部门、查询期间、已归集成本、数据完整性，全部只读。
2. 成本类别汇总：按七类成本展示金额、占比、来源状态和最后更新时间。
3. 成本来源明细：统一展示每笔成本事实的期间、成本类别、来源单据、归集部门、直接或分摊、金额及财务回写状态。
4. 抽屉只提供“关闭”；来源单号按路由可用性提供穿透链接，不提供任何维护操作。

## 9. 业务规则与校验

| 编号 | 触发时机 | 条件 | 处理结果 | 提示文案 |
| --- | --- | --- | --- | --- |
| R01 | 页面初始化 | 页面首次打开 | 会计期间范围起止值均带出当前会计期间；项目和成本类型为空 | 不适用 |
| R02 | 查询 | 选择会计期间范围、项目或成本类型 | 按条件同步刷新趋势图和列表并返回第 1 页 | 不适用 |
| R03 | 汇总 | 成本来源单据未审核、已作废或已被有效红字完全冲销 | 不计入已归集成本 | 不适用 |
| R04 | 汇总 | 采购订单、采购发票、付款或预付款仅表明采购范围、票据或资金事实 | 不直接计入项目成本；仅按确认后的履约、消耗、费用、人工、折旧、分摊或调整事实计入 | 不适用 |
| R05 | 汇总 | 实物采购尚在库存且未形成有效物资出库或转固折旧 | 不计入项目物资消耗成本 | 不适用 |
| R06 | 汇总 | 蓝字成本存在有效红字、退回或冲销 | 按来源明细净额计入，保留蓝红记录及关联关系 | 不适用 |
| R07 | 汇总 | 成本事实直接关联项目 | 按项目直接归集，并保留成本归集部门 | 不适用 |
| R08 | 汇总 | 成本事实通过已执行分摊规则分配至项目 | 按分摊结果计入间接分摊，并展示规则名称和版本 | 不适用 |
| R09 | 汇总 | 已审核成本调整单关联当前项目和期间 | 将调整净额计入成本调整，不改写原来源金额 | 不适用 |
| R10 | 计算 | 任一金额来源未知或尚未接入 | 金额显示“-”或当前已归集值，同时数据完整性标记具体待补原因；不得以 0 代替未知 | 成本数据尚未完整，请查看待补来源 |
| R11 | 计算 | 所有规定来源已完成、分摊已执行且期间状态符合确认条件 | 数据完整性方可标记“完整” | 不适用 |
| R12 | 计算 | 计算当前已归集成本 | 暂按“采购服务成本 + 物资消耗成本 + 费用成本 + 人工成本 + 折旧摊销 + 间接分摊 + 成本调整”展示；正式公式须经第 15 章确认 | 不适用 |
| R13 | 计算 | 计算直接成本 | 暂汇总直接归集至项目的采购服务、物资、费用、人工及折旧成本；具体类别边界待确认 | 不适用 |
| R14 | 计算 | 计算间接成本 | 暂汇总通过分摊规则进入项目的金额；不得与直接成本重复 | 不适用 |
| R15 | 计算 | 成本类别金额和已归集成本均有有效数值 | 类别合计必须等于已归集成本；不一致时标记异常并禁止显示“完整” | 成本分类合计与项目成本不一致 |
| R16 | 跨报表核对 | 所属公司、期间和成本范围一致 | 项目成本汇总总额应等于部门成本中的“项目归集成本”总额；尚未分摊的部门公共成本单独核对，不强制计入具体项目 | 项目成本与部门项目归集成本存在差异 |
| R17 | 权限过滤 | 项目或来源单据超出用户组织、项目或财务权限 | 在数据源层排除，趋势图和列表同步排除 | 不适用 |
| R18 | 来源穿透 | 来源页面不存在、记录未接入或用户无权限 | 不提供可点击链接，保留来源类型、单号和状态文本 | 暂无可访问的来源页面 |

删除、状态变更及主明细编辑：本页面只读，不适用。

## 10. 关键交互

1. 查询或重置后，会计月成本趋势图和项目列表使用同一条件刷新；列表回到第 1 页，不显示通用成功 Toast。
2. 会计期间范围默认当前会计期间至当前会计期间，允许清空不选；起始期间不得晚于结束期间。
3. 会计月成本趋势按月份升序展示，缺失月份显示缺失状态，不自动补 0。
4. 项目列表固定每页 5 条；项目编码固定在左侧，宽表仅表格区域横向滚动；合计行固定汇总本次要求的七个金额字段。
5. 点击项目编码打开右侧明细抽屉；抽屉加载期间显示局部骨架，加载失败时保留项目摘要并提供重试。
6. 明细抽屉内成本类别汇总与来源明细联动；无来源记录时展示标准空状态，不显示伪造金额。
7. 点击可穿透来源单号时通过父窗口打开或切换对应菜单标签；返回本页时保留查询、页码和滚动位置。
8. 页面整体加载失败时展示标准错误状态；单一数据源失败时保留其他已加载数据，并将数据完整性标记为待补。
9. 所有金额使用本位币、千分位和 2 位小数；负数保留负号并使用统一负值样式；日期、日期时间符合项目格式。
10. 页面支持直接打开和 iframe 嵌入；无编辑数据，不产生未保存离开提示。

## 11. 业财关联

### 11.1 归集维度

- 所属公司/核算主体、会计期间、项目、项目类型、项目状态、成本归集部门、成本类别、来源单据、币种和财务回写状态。

### 11.2 上下游关系

- 上游来源：项目立项、已审核服务结算、已审核物资出库、费用归集、人工成本分配、用友折旧摊销、间接费用分摊、已审核成本调整。
- 当前单据：项目成本只读汇总及成本事实明细。
- 下游单据：本页不产生下游业务单据；分析结果后续可供项目成本、项目利润和经营分析使用。
- 穿透链路：`项目 -> 成本类别汇总 -> 成本事实明细 -> 业务来源单据 -> 用友凭证/核算结果`。

### 11.3 财务影响

本页不生成或修改应付、付款、发票、库存、资产、成本或财务凭证，只展示业务成本事实及用友回写结果。采购订单不是成本事实；物资采购入库后仍在库存时不直接计入项目成本，物资出库后按确认的库存计价结果计入；服务在履约结算确认后形成成本依据；付款和预付款只影响资金，不直接形成成本。可抵扣进项税、不可抵扣税额、价差、暂估与正式成本之间的处理方式待确认。

- C06：人工成本来源及计算范围，是否包含工资、奖金、单位承担社保公积金、福利和外包人工；按工时、人员比例还是其他规则分配。
