# 付款申请页面蓝图

## 1. 蓝图信息

| 项目 | 内容 |
| --- | --- |
| 蓝图状态 | 已确认 |
| 页面名称 | 付款申请 |
| 页面编码 | `payment-request` |
| 业务域 | 支出付款（expense） |
| 菜单路径 | 采购管理 / 付款申请 |
| 页面类型 | 列表详情一体、流程审批单据 |
| 计划输出 | `pages/expense/payment-request.html` |

## 2. 业务目标与主线

付款申请以单一供应商的一笔对公付款为单据维度，根据是否存在合同切换合同、项目、收款账户、合同金额及可申请金额的维护方式。

```text
供应商 -> 合同/项目 -> 付款申请 -> 付款单
```

发票与采购业务的追溯关系仍由采购收票和财务核销链路保留，不在本页重复选择。

## 3. 页面组成

### 3.1 列表视图

- 查询条件：申请单号、供应商、是否有合同（是、否）、合同名称、项目、状态、付款状态（待付款、已付款）、计划付款日期。
- 列表字段固定为：申请单号、状态、付款金额、计划付款日期、供应商、项目、是否有合同、合同名称、付款状态、申请人、申请时间、操作。
- 列表每页固定 5 条；申请单号可进入详情；仅草稿可删除。
- 金额、数量统一保留两位小数，单价统一保留四位小数；金额、数量和单价均右对齐。

### 3.2 详情视图

- 页签一：基础信息。
- 页签二：附件。
- 附件页签使用公共上传组件，附件列表仅展示文件名、大小、上传人、上传时间、操作，不展示资料类型。
- 取消“发票结算明细”页签。
- 不展示采购订单明细表，不提供采购订单明细选择入口。

## 4. 字段定义

### 4.1 基础信息

| 字段 | 控件 | 必填 | 规则 |
| --- | --- | --- | --- |
| 申请单号 | 输入框 | 否 | 系统生成，只读 |
| 状态 | 状态字段 | 否 | 系统维护，只读 |
| 供应商 | 弹窗选择 | 是 | 弹窗仅展示供应商编码、供应商名称；单选 |
| 是否有合同 | 下拉框 | 是 | 是、否 |
| 合同名称 | 下拉框 | 条件必填 | 是否有合同为“是”时必填且支持下拉选择；为“否”时取消必填并禁用 |
| 项目 | 弹窗选择 | 条件必填 | 有合同时由合同自动带出；无合同时必填并手动选择 |
| 收款账户 | 下拉框 | 是 | 有合同时由合同自动带出；无合同时按供应商提供有效账户下拉 |
| 收款银行 | 输入框 | 否 | 根据收款账户自动带出，只读，不显示必填标识 |
| 合同金额 | 金额 | 否 | 有合同时由所选合同自动带出合同总额；无合同时为空；只读 |
| 可申请金额 | 金额 | 否 | 有合同时按合同金额扣除已付款及有效付款申请占用金额自动计算；无合同时显示当前单据默认值；只读 |
| 发票金额 | 金额 | 否 | 当前付款申请对应的有效发票金额，只读 |
| 付款金额 | 金额输入 | 是 | 经办人录入，必须大于 0，且不得超过可申请金额和发票金额 |
| 付款方式 | 下拉框 | 是 | 电汇、承兑 |
| 计划付款日期 | 日期选择 | 是 | 默认空值，由申请人选择 |
| 付款原因 | 输入框 | 是 | 必填，说明本次对公付款用途 |
| 付款单号 | 输入框 | 否 | 付款单生成后回写，只读 |
| 申请人 | 输入框 | 否 | 当前登录人，只读 |
| 申请时间 | 日期时间 | 否 | 系统时间，只读 |
| 所属公司 | 输入框 | 否 | 当前公司，只读 |
| 备注 | 输入框 | 否 | 选填 |

## 5. 交互与校验

1. 是否有合同为“是”时，合同名称必填且可下拉选择；选择合同后自动带出项目、收款账户、收款银行和合同金额，并自动计算可申请金额，项目和收款账户不可手工修改。
2. 是否有合同为“否”时，合同名称取消必填并禁用，合同金额为空，可申请金额显示默认值；项目必填且通过弹窗选择；收款账户按当前供应商提供有效账户下拉。
3. 首次选择时，有合同模式仅合同名称显示“请选择”，项目保持空白；无合同模式合同名称保持空白，仅项目显示“请选择”。
4. 更换供应商或切换是否有合同时，清空不再适用的合同、项目、账户、银行及合同金额；可申请金额按当前模式重新计算或恢复默认值，防止残留错误关系。
5. 付款金额必填，必须大于 0，保留两位小数，且不得超过可申请金额和发票金额。
6. 付款方式必填，仅支持电汇、承兑；付款原因必填。
7. 收款银行不显示必填标识；付款单号由后续付款单生成后回写。
8. 审批通过只形成付款占用；实际银行成功后才计入已付金额。
9. 金额、数量保留两位小数，单价保留四位小数；用户录入后按对应精度规范化显示。

## 6. 状态与操作

| 状态 | 详情模式 | 可执行操作 |
| --- | --- | --- |
| 草稿 | 可编辑 | 保存草稿、提交、删除 |
| 待审核 | 只读 | 审核通过、驳回、查看流程 |
| 已审核 | 只读 | 查看、终止 |
| 已终止 | 只读 | 查看 |
