# 智能体运营分析页面蓝图

## 1. 页面定位

| 项目 | 说明 |
|---|---|
| 菜单路径 | 报表管理 / 智能体运营分析 |
| 页面类型 | 项目列表 + 三页签详情 |
| 输出页面 | `pages/project-overview.html` |
| 数据口径 | 项目主数据由系统带入；控制效果由售后服务人员定期手工新增 |
| 计算边界 | 系统不采集原始指标、不计算变化率、不自动形成效果结论 |

页面用于按项目查看智能体运营基础信息、团队配置及不同周期的控制效果记录。每次控制效果补录均新增一条独立记录，不保留“控制前/控制后”双值。

## 2. 主列表

### 2.1 查询条件

1. 项目名称：模糊查询。
2. 项目状态：下拉查询。

### 2.2 列表字段

项目名称、区域、运营规模（万吨/日）、项目状态、项目经理、技术负责人、实施人员、AI-OS配置人员、算法工程师、销售负责人、控制开始时间、操作。

- 固定每页 5 条，通过分页切换，不显示页容量选择器。
- 控制开始时间统一显示 `YYYY-MM-DD`。
- 控制开始时间表头显示排序图标，点击后在升序和降序之间切换，空日期固定排在末尾。
- 项目数据不允许在本页面新增、编辑或删除。
- 操作列仅保留“详情”。
- 主列表提供复选框；单选一条项目后，列表页标题右上角“智控时间调整”按钮启用。点击后弹窗自动带出所选项目的智控开始时间、智控结束时间；结束时间不得早于开始时间，保存后同步列表与详情数据。未选或多选时按钮禁用。

## 3. 详情页签

详情页仅设置“基础信息”“团队&配置”“控制效果”三个页签。桌面端标准详情表单统一每行3个字段；页签内容区不重复显示与页签同义的左上角标题，直接展示字段、工具栏或业务卡片。

### 3.1 基础信息

严格显示以下 16 个只读字段：

1. 项目编码
2. 项目名称
3. 区域
4. 运营规模（万吨/日）
5. 项目状态
6. 污水类型
7. 生化工艺
8. 排放标准
9. 出水COD（mg/L）
10. 出水氨氮（mg/L）
11. 出水总氮（mg/L）
12. 出水总磷（mg/L）
13. 客户编码
14. 客户名称
15. 业主单位
16. 运营单位

### 3.2 团队&配置

上部为项目团队：

| 字段 | 交互 |
|---|---|
| 项目经理 | 只读 |
| 销售负责人 | 只读 |
| 技术负责人 | 下拉多选 |
| 实施人员 | 下拉多选 |
| AI-OS配置人员 | 下拉多选 |
| 算法工程师 | 下拉多选 |

下部为运行配置：

| 字段 | 交互 |
|---|---|
| AI-OS地址 | 可编辑配置 |
| 已部署智能体 | 多值标签展示，只读 |
| 智控开始时间 | 可编辑日期，`YYYY-MM-DD` |
| 智控结束时间 | 可编辑日期，`YYYY-MM-DD`，不得早于开始时间 |
| 剩余使用时长 | 只读 |

### 3.3 控制效果

固定配置区：

- 控制策略：可编辑文本域，独占一行。
- 验收报告：附件上传控件，独占一行，位于控制策略下方；支持点击“上传附件”选择文件并回显文件名。

指标趋势区位于固定配置区与周期记录区之间：

- 默认展示“吨水电耗”柱状图，支持在柱状图与折线图之间切换。
- 支持从六项控制效果指标中选择任一指标；图表纵轴单位随指标自动切换，数据按评估周期开始日期升序排列，但不显示底部周期坐标文字。
- 图表数据仅来源于下方已保存的控制效果记录；新增保存、编辑保存、删除后立即同步刷新，不进行额外计算。
- 支持将当前所选指标和图表类型导出为 PNG 图片；无有效记录时展示空状态。

周期记录区采用单列卡片列表，每行只显示一张卡片。卡片头部仅显示评估周期，不显示“记录1、记录2”等序号。点击“新增控制效果”后，在卡片列表顶部新增一张处于编辑状态的空白卡片。每张卡片包含：

| 字段 | 类型 | 必填 | 校验/单位 |
|---|---|---|---|
| 开始日期 | 日期 | 是 | `YYYY-MM-DD` |
| 结束日期 | 日期 | 是 | 不得早于开始日期 |
| 吨水电耗 | 数值 | 是 | 非负，kWh/m³ |
| 吨水风机电耗 | 数值 | 是 | 非负，kWh/m³ |
| 去除单位氨氮电耗 | 数值 | 是 | 非负，kWh/kg |
| 去除单位COD电耗 | 数值 | 是 | 非负，kWh/kg |
| 吨水PAC药耗 | 数值 | 是 | 非负，kg/千吨水 |
| 吨水碳源药耗 | 数值 | 是 | 非负，kg/千吨水 |
| 整体运行效果评估 | 文本域 | 是 | 售后人员直接填写结论 |
| 新增人员 | 文本 | 系统生成 | 显示新增记录的人员姓名 |
| 新增时间 | 日期时间 | 系统生成 | `YYYY-MM-DD HH:mm:ss` |

卡片默认只读，支持编辑、保存、取消和删除。删除前必须二次确认；保存后立即展示，不设置提交、审核、发布流程。

## 4. 业务规则

1. 每个评估周期对应一条独立控制效果记录，不在同一记录内维护控制前值和控制后值。
2. 新增记录的所有业务字段默认为空，不复制上一期指标。
3. 同一时刻只允许一张控制效果卡片处于新增或编辑状态。
4. 开始日期、结束日期、六项指标和整体运行效果评估均为必填。
5. 六项指标必须为非负数；系统只记录录入值，不做衍生计算。
6. 取消新增时直接移除未保存卡片；取消编辑时恢复原值。
7. 控制效果与当前项目编码绑定，不允许跨项目移动。
8. 主列表不展示控制效果字段，也不提供控制效果快捷展开入口。

## 5. 权限与实施边界

- 售后服务人员：新增、编辑、删除控制效果记录；维护控制策略并上传验收报告。
- 项目配置维护人员：维护技术负责人、实施人员、AI-OS配置人员、算法工程师及AI-OS地址。
- 项目经理、销售负责人及其他授权人员：查看项目详情和控制效果。
- 本期为前端高保真原型，演示数据在页面内即时更新；正式实施时由后端按项目、操作人和操作时间持久化。

## 6. 验收要点

1. 菜单“报表管理 / 智能体运营分析”正确打开本页面。
2. 主列表固定显示 5 条数据，查询、分页和详情入口可用。
3. 详情只有三个页签，基础信息完整且无重复页签标题。
4. 团队四类人员字段可多选，AI-OS地址可编辑，已部署智能体支持多值展示。
5. 控制策略可编辑；验收报告支持附件上传并位于控制策略下方，原文本域已移除。
6. 控制效果每次新增空白卡片，六项指标均为单值，不出现控制前/控制后字段。
7. 卡片新增、编辑、保存、取消、删除及删除确认完整可用。

## 7. 机器可验收布局约束

- `uiConstraints.listPageSize = 5`：主列表固定每页 5 条。
- `uiConstraints.detailFormColumns = 3`：详情表单桌面端每行 3 个字段。
- `uiConstraints.tabSectionTitles = false`：页签直接内容区不得重复显示页签同义标题。
- `uiConstraints.effectCardsPerRow = 1`：控制效果记录每行 1 张卡片。
- `uiConstraints.effectMetricColumns = 3`：控制效果卡片内指标桌面端每行 3 项。
- 页面生成前必须通过 Schema 约束检查；生成后必须在独立页面和菜单 iframe 两种环境中检查实际布局。
