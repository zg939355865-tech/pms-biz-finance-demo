# 项目运维记录页面蓝图

## 1. 页面定位

| 项目 | 说明 |
|---|---|
| 菜单路径 | 报表管理 / 项目运维记录 |
| 菜单位置 | 智能体运营分析下方 |
| 页面类型 | 项目问题记录主从工作台 |
| 输出页面 | `pages/report/project-operations-record.html` |
| 业务用途 | 按项目查看并维护问题记录，不维护项目运维整单 |

## 2. 主从布局

- 左侧为项目导航，右侧为当前项目的问题记录。
- 项目本身只读，不提供整单新增、编辑、删除、提交和刷新操作。
- 初始选中第一个项目；点击其他项目仅切换右侧问题记录，不离开工作台。
- 左右两侧标题均不展示统计数量。

## 3. 左侧项目区

### 3.1 查询条件

- 仅展示一个无标签搜索框，提示语为“搜索项目名称 / 客户名称”。
- 输入关键字后即时匹配项目名称或客户名称，不展示“查询”“重置”按钮。

### 3.2 项目列表

- 每项仅展示项目名称和客户名称。
- 项目名称使用较大、较醒目的主文字；客户名称使用较小的辅助文字。
- 项目项采用紧凑高度，不随左侧容器剩余高度拉伸。
- 不显示复选框、项目类型、记录日期、问题数量、创建人、创建时间和操作列。
- 不提供整单新增、编辑、删除或批量删除。
- 保持每页 5 条及“共 N 条记录、5条/页”。

## 4. 右侧问题记录

- 顶部显示当前项目名称，客户名称作为辅助信息。
- 删除原“基础信息”区域，右侧仅显示“问题记录”。
- “新增问题”和“AI数字员工分析”位于右侧项目标题右上角。
- 问题记录采用纵向卡片展示，每张卡片包含：发行日期、创建人、问题描述、解决方案；问题记录标题不展示数量。
- 问题描述与解决方案按参考截图的“标签 + 长文本”形式分行展示，卡片之间使用分隔与留白区分。
- 只支持“新增问题”和单卡片“删除”；不支持修改既有问题记录。
- 点击“新增问题”打开弹窗；填写发行日期、问题描述、解决方案，创建人自动带出当前用户；确认后新增只读卡片。
- 删除问题记录前进行二次确认。

## 5. AI 数字员工分析

- 点击右上角“AI数字员工分析”打开分析弹窗，不离开当前项目。
- 弹窗先展示分析过程，包括问题汇总、主题识别、风险评估和建议生成；同时展示综合结论、风险等级、重点问题及建议措施。
- 本期使用可演示的静态分析结果，明确属于原型展示，不代表已接入真实 AI 推理服务。

## 6. 原型数据与边界

- 提供 6 个项目样例以验证项目分页，每个项目包含客户名称和若干问题记录。
- 本期为静态高保真原型；项目切换、问题新增和删除仅用于页面交互演示，不代表后端持久化已接通。

## 7. 验收要点

1. 左侧只有项目/客户关键字搜索框，无标题数量、查询和重置按钮；项目项只显示项目名称和客户名称且高度紧凑。
2. 页面不存在整单新增、编辑、删除、批量删除、提交和基础信息区域。
3. 右侧问题记录以卡片展示，并包含发行日期、创建人、问题描述、解决方案。
4. 新增问题通过弹窗完成；确认新增、取消和删除问题实际可操作，删除执行二次确认。
5. “AI数字员工分析”弹窗同时展示分析过程和分析结果。
6. 1440px、2048px 无页面级横向溢出，项目列表固定每页 5 条，并可在菜单 iframe 中打开。
