## 2. 需求结论与设计原则

1. 页面采用“年度批量生成 + 列表内维护 + 单一启动期切换”的配置模式。
2. 顶部仅保留“开启会计期间、 新增会计期间”，去除“批量删除、关闭期间”。
3. 表格选择器复用项目通用复选框样式；交互语义仍为单选，避免同时开启多个期间。
4. 新增不进入详情页，只在弹窗选择年度，并按自然月一次生成12个会计期间；列表仅显示期号（如1、2）。
5. 开启新期间时，如存在已启动期间，系统自动将原期间改为“否”，再将所选期间改为“是”；不存在时直接开启。
6. 业务日期控制继续采用开始日期、结束日期闭区间，边界日可选。
7. 查询区采用紧凑行内布局：字段标签左对齐并按文字内容自适应宽度，标签与控件保持8px间距；首个“年度”标签与列表复选框左边界处于同一垂直基线。
8. 列表首次加载及新增年度后，均按开始日期倒序排列。
9. 新增弹窗的年度候选项动态排除列表中已经生成会计期间的年度；查询条件仍保留历史年度用于检索。

## 3. 业务目标

按年度快速建立会计期间，减少逐月维护成本；通过唯一启动期间统一控制相关业务单据的业务日期，避免跨期录入。

## 4. 用户与权限

- 财务管理员：查询、新增年度期间、编辑期间日期、开启期间。
- 业务人员：只消费当前启动期间的业务日期范围，不直接维护本页面。
- 无维护权限用户：页面只读，操作按钮隐藏或禁用。

## 5. 页面范围

- 会计期间查询、固定五条分页。
- 通用复选框单选期间。
- 列表内编辑开始日期、结束日期。
- 年度批量生成12期弹窗。
- 开启期间确认弹窗及自动关旧开新。
- 不提供详情页、独立关闭入口、批量删除和行删除。

## 6. 页面与交互流程

```text
进入列表
  ├─ 新增会计期间 → 选择年度 → 生成12个自然月期间 → 返回列表
  ├─ 编辑 → 当前行日期可编辑 → 保存/取消 → 返回只读行
  └─ 勾选未启动期间 → 开启会计期间 → 确认
       ├─ 存在启动期：自动关闭原启动期 → 开启所选期
       └─ 不存在启动期：直接开启所选期
```

## 7. 列表页设计

### 7.1 查询条件

| 顺序 | 字段 | 控件 | 说明 |
| --- | --- | --- | --- |
| 1 | 年度 | 下拉选择 | 示例：2026 |
| 2 | 会计期间 | 下拉选择 | 选项固定为1至12 |
| 3 | 是否启动 | 下拉选择 | 是、否 |

查询标签采用左对齐和内容自适应宽度，标签与控件间距为8px；首个“年度”标签与表格首列复选框按同一内容边界对齐，避免短标签后出现大块留白。

### 7.2 列表字段

| 顺序 | 字段 | 示例 | 对齐 | 编辑规则 |
| --- | --- | --- | --- | --- |
| 1 | 年度 | 2026 | 左 | 只读 |
| 2 | 会计期间 | 1 | 左 | 只读，显示自然月期号 |
| 3 | 开始日期 | 2026-05-01 | 左 | 点击编辑后可修改 |
| 4 | 结束日期 | 2026-05-31 | 左 | 点击编辑后可修改 |
| 5 | 是否启动 | 是 / 否 | 中 | 系统维护 |
| 6 | 操作 | 编辑 | 中 | 编辑时切换为保存、取消 |

列表左侧增加通用复选框列，控件尺寸、选中态、禁用态和焦点态均复用资源中心表格选择器样式。选择模式为单选，不显示自定义单选圆点。

表格不使用少字段强制均分居中布局，单元格采用8px紧凑水平内边距，并按字段语义对齐：年度、会计期间和日期左对齐，状态与操作居中，缩短复选框与年度数据之间的视觉距离。

列表默认按“开始日期”倒序排列，初始示例会计期间为1、2、3、4、5、6、7，最新期间显示在最前；新增年度后重新执行相同排序。

## 8. 状态与权限

本页面不使用审批状态，仅使用“是否启动”。任一时刻只允许一条记录为“是”。

| 状态 | 可选中 | 可编辑日期 | 可执行开启 |
| --- | --- | --- | --- |
| 否 | 是 | 是 | 是 |
| 是 | 是 | 是 | 否 |

## 9. 新增会计期间弹窗

| 项目 | 设计 |
| --- | --- |
| 弹窗标题 | 新增会计期间 |
| 字段 | 年度，下拉选择，必填 |
| 提示 | 选择年度后自动生成12个自然月期间；已经生成会计期间的年度不再显示在候选项中 |
| 主按钮 | 生成12个期间 |
| 结果 | 生成1至12期；开始日期为月初，结束日期为月末；是否启动均为“否” |
| 特殊处理 | 不形成详情页，不逐月录入 |

## 10. 开启会计期间弹窗

弹窗必须明确展示以下说明：

- 若已存在启动的会计期间，系统自动关闭当前期间并开启所选期间。
- 若不存在启动的会计期间，直接开启所选期间。
- 开启后，相关业务单据的业务日期只能选择所选期间开始日期至结束日期。

## 11. 业务规则

| 编号 | 场景 | 处理 |
| --- | --- | --- |
| R01 | 新增年度 | 按自然月自动生成12条，会计期间显示为1至12 |
| R02 | 年度已存在 | 阻止重复生成并提示“该年度会计期间已存在” |
| R03 | 编辑日期 | 仅当前行开始日期、结束日期切换为可编辑 |
| R04 | 开始日期晚于结束日期 | 阻止保存并提示“结束日期不得早于开始日期” |
| R05 | 勾选列表 | 通用复选框外观，最多保留一条选中记录 |
| R06 | 开启未启动期间且存在启动期 | 原启动期自动改为“否”，所选期改为“是” |
| R07 | 开启未启动期间且不存在启动期 | 所选期直接改为“是” |
| R08 | 业务日期选择 | 仅允许当前启动期间开始日期至结束日期，两个边界日均可选 |
| R09 | 无启动期间 | 阻止新增、提交、审核产生新业务结果 |
| R10 | 历史单据 | 保留原业务日期；重新提交时按当前启动期间重新校验 |
| R11 | 页面首次加载或新增年度 | 按开始日期倒序排列，最新期间位于前页 |
| R12 | 打开新增弹窗 | 从年度候选项中排除已经存在会计期间的年度 |

## 12. 异常与反馈

- 未选择记录时，“开启会计期间”禁用。
- 选择已启动记录时，“开启会计期间”禁用。
- 行编辑同时只允许一行，存在编辑行时不得切换另一行。
- 新增年度重复、年度未选择、日期区间错误均在当前弹窗或当前行就近反馈。
- 保存、生成和开启成功后刷新列表计数与分页；不进入详情页。

## 13. 业财与日期控制

业务链路：`启动会计期间 → 业务单据业务日期 → 提交/审核校验 → 业务处理 → 财务凭证`。

本页面发布业务日期闭区间控制契约；采购、收入、物资、费用和资金单据需逐页接入该契约后，才能形成实际拦截。

## 14. 原型与视觉要求

- 延续项目深蓝科技风，不新增页面私有视觉体系。
- 复选框使用资源中心 `.schema-select-col input[type="checkbox"]` 通用样式。
- 表格表头、行高、按钮、日期控件、弹窗圆角和阴影均复用现有组件样式。
- 查询标签按内容自适应宽度并与控件保持8px间距；列表字段按语义对齐，不产生复选框后的大块空白。
- 列表固定每页5条，不显示页容量下拉；页面整体无横向和纵向业务区滚动。
- 操作列固定在右侧；宽度足以显示“保存、取消”。
