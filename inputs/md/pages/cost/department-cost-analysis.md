## 2. 需求理解与 AI 假设

### 2.1 用户明确要求

1. 根据当前 PMS 业务信息生成“部门成本分析”页面蓝图。
2. 用户已要求基于本蓝图生成 Schema、HTML，并接入菜单路由。
3. 菜单及页面标题统一改为“部门成本”。
4. 查询条件调整为会计期间范围、部门、成本类型；会计期间范围默认 2026-01 至 2026-12，允许清空不选择；部门为下拉多选。
5. 页面去除指标区和部门成本构成图，仅保留查询条件、部门成本趋势和部门成本列表。
6. “部门成本对比”改为“部门成本趋势”。
7. 部门成本列表去除说明，列表字段调整为年度-会计期间、部门编码、部门名称、成本总计及六类成本，并增加对应金额合计行。

### 2.2 AI 补充内容与假设

1. 页面定位为只读分析页，不在本页维护成本来源、分摊规则或成本调整单。
2. 以“所属公司 + 会计期间 + 成本归集部门”为主汇总粒度；组织层级调整后的历史成本仍保留成本发生时的归集部门快照。
3. 部门成本来源与项目成本一致，暂按采购服务履约、物资消耗、费用报销、人工、折旧摊销、间接费用分摊和成本调整七类展示。
4. **AI 假设：**页面展示部门成本趋势和部门列表，点击部门编码打开右侧只读明细抽屉。
5. **AI 假设：**每笔成本事实必须有成本归集部门，可同时关联项目；部门成本和项目成本是同一事实的两个分析维度，不是两次记账。
6. **AI 假设：**部门成本拆分为“项目归集成本”和“部门公共成本”；前者同时参与对应项目成本分析，后者在完成分摊前只保留在部门，分摊至项目后通过唯一分摊明细避免重复。
7. **AI 假设：**人工、费用、折旧和分摊来源未完成时展示当前已归集金额及具体待补状态，不将不完整金额表述为最终真实部门成本。
8. 影响真实结果的成本确认、部门归属、组织变更、人工、折旧、费用池、分摊和结账规则列入第 15 章待确认项。

## 3. 业务目标与范围

### 3.1 业务目标

统一展示各成本归集部门在指定期间内承担的成本规模、类别结构、会计月变化、项目与公共成本构成和来源完整性，支撑部门费用责任分析、成本分摊复核和项目成本核对。

### 3.2 主要使用人员

- 公司管理层：比较部门成本规模、构成和变化情况。
- 部门负责人：查看本部门项目成本、公共成本及主要来源。
- 财务及成本会计：复核部门归属、公共费用池、分摊结果和财务回写状态。
- 项目经理：核对本项目成本在各承担部门的分布。

### 3.3 本次包含

- 按会计期间范围、部门和成本类型查询；会计期间范围默认 2026-01 至 2026-12，也可清空不选择。
- 部门支持下拉多选。
- 展示部门成本趋势，不展示指标卡和部门成本构成图。
- 按年度-会计期间和部门展示成本总计、服务采购、物资消耗、费用报销、人工成本、折旧摊销和间接费用，并在列表下方汇总对应金额。
- 点击部门编码查看部门成本摘要、项目贡献汇总和成本来源明细。
- 从来源单号穿透至可访问的现有业务单据；未建设或未接入的数据源仅展示状态。

### 3.4 本次不包含

- 部门档案和组织架构维护。
- 成本调整单新增、审核和反审核。
- 公共费用池维护、分摊规则配置、分摊执行和撤销。
- 人工、折旧、库存计价、月末结账、反结账和成本重算。
- 部门预算、收入、利润、绩效或排名考核；本页只展示成本。
- 修改业务来源、成本归属或财务凭证。

### 3.5 业务链路

```text
组织部门档案
  -> 已审核服务结算 / 已审核物资出库 / 已审核费用 / 月度人工 / 用友折旧 / 间接费用分摊 / 已审核成本调整
  -> 成本事实明细（成本归集部门必填，项目按业务场景关联）
  -> 按所属公司 + 会计期间 + 成本归集部门汇总
  -> 部门成本
  -> 与项目成本分析及用友核算结果对账
```

## 4. 页面组成与关系

| 视图 | 载体 | 说明 |

页面关系：

## 5. 页面区域

### 5.1 列表视图

1. 页面头：显示标题“部门成本”，不提供新增或批量业务操作。
2. 查询区域：按会计期间范围、部门、成本类型依次展示；会计期间范围使用月份选择，默认起止均为当前会计期间，允许清空；部门使用下拉多选。
3. 图表区域：部门成本趋势折线图独占整行展示；每个选中部门对应一条曲线，图例在右侧纵向排列，曲线按部门查询条件显示，未选择部门时展示全部部门。查询和重置同步更新图表，期间无数据时显示空状态。
4. 部门成本列表：不展示说明；按年度-会计期间、部门编码、部门名称、成本总计、服务采购、物资消耗、费用报销、人工成本、折旧摊销、间接费用依次展示，并在列表下方增加金额合计行。
5. 分页区域：固定每页 5 条，不提供页容量选择，不产生业务页面内部纵向滚动条。

### 5.2 详情视图

1. 部门摘要：展示所属公司、部门编码、部门名称、上级部门、部门负责人、查询期间、项目数量、已归集成本、项目归集成本、部门公共成本和数据完整性，全部只读。
2. 项目贡献：按项目展示当前部门承担的七类成本及合计，项目编码可穿透至项目成本分析。
3. 成本来源：展示每笔成本事实的期间、成本类别、项目、来源单据、承担类型、归集方式、金额及财务回写状态。
4. 抽屉只提供“关闭”；不存在页面路由或没有权限的来源单据不显示可点击链接。

## 10. 关键交互

1. 查询或重置后，指标卡、成本构成图、部门成本趋势图和部门列表同步刷新；列表回到第 1 页，不显示通用成功 Toast。
2. 年度默认当年；会计期间按月份筛选。
3. 成本构成图点击类别后，部门列表和抽屉成本来源临时筛选该类别；再次点击或重置恢复全部类别。
4. 部门成本趋势按月份顺序展示当前年度各会计月成本变化。
5. 部门列表固定每页 5 条；部门编码固定左侧，金额右对齐，宽表仅表格区域横向滚动。
6. 点击部门编码打开右侧明细抽屉；抽屉加载期间显示局部骨架，失败时保留部门摘要并允许重试。
7. 抽屉默认展示“项目贡献”，切换“成本来源”后按统一成本事实查看明细；无记录时显示标准空状态。
8. 点击项目编码打开项目成本分析并传递所属公司、期间和项目；点击来源单号通过父窗口打开对应业务页面标签。
9. 单一数据源失败时保留其他已加载数据，并将相关部门数据完整性标记为待补；不使用 0 补齐未知来源。
10. 金额使用本位币、千分位和 2 位小数，负数保留负号；日期、日期时间和状态标签符合项目规范。
11. 页面支持直接打开和 iframe 嵌入；无编辑数据，不产生未保存离开提示。

## 11. 业财关联

### 11.1 归集维度

- 所属公司/核算主体、会计期间、成本归集部门、组织层级、项目、成本承担类型、成本类别、来源单据、币种和财务回写状态。

### 11.2 上下游关系

- 上游来源：组织部门档案、项目立项、已审核服务结算、已审核物资出库、费用归集、人工成本分配、用友折旧摊销、间接费用分摊、已审核成本调整。
- 当前单据：部门成本分析只读汇总及成本事实明细。
- 下游单据：本页不产生下游业务单据；分析结果后续可供部门成本控制、项目成本核对和经营分析使用。
- 穿透链路：`部门 -> 项目贡献/成本类别汇总 -> 成本事实明细 -> 业务来源单据 -> 用友凭证/核算结果`。

### 11.3 财务影响

本页不生成或修改成本、库存、资产、应付、付款、发票或财务凭证。部门是成本责任和分析维度，不自动替代项目、核算主体或会计科目。采购订单、发票、付款和预付款不直接形成部门成本；服务履约、物资消耗、费用、人工、折旧、分摊和调整按有效事实进入部门成本。同一事实可以同时被项目和部门分析，但财务金额只能记账一次。
