## 2. 需求理解与 AI 假设

### 2.1 用户明确要求

1. 支出合同支持录入基础信息、合同标的明细和附件，不设置审批流程。
2. 基础信息字段为：合同编号、合同名称、状态、合同类型、合同总金额、签订日期、生效日期、截止日期、合同负责人、供应商、结算币别、统一社会信用代码、收款账户、收款银行、付款方式、发票类型、创建人、创建时间、所属公司、备注；详情不展示业务状态。
3. 合同编号由用户手工输入，不由系统自动生成。
4. 合同总金额根据标的明细行金额自动计算，不允许手工修改。
5. 基础信息与标的明细位于同一个“基础信息”页签，附件保留独立页签。
6. 标的明细的“单价”调整为“含税单价”，明细金额按数量乘以含税单价计算。
7. 列表字段依次为：合同编号、状态、业务状态、合同名称、供应商、合同类型、合同负责人、签订日期、生效日期、截止日期、创建人、创建时间。
8. 查询条件同时包含状态、业务状态和合同类型，并保留合同编号或名称、供应商、合同负责人和签订日期。
9. 合同相对方从供应商档案中选择，并带出统一社会信用代码和默认收款账户；同一供应商存在多个收款账户时允许再次下拉选择，收款银行根据所选账户自动带出。
10. 合同标的明细为选填；未录入标的明细时，必须至少上传一份合同附件才能保存。
11. 支出合同本身不关联项目；项目由采购订单关联，采购申请与支出合同没有直接关系。
12. 支出合同只是普通采购订单和紧急采购订单的可选关联项。
13. 合同负责人使用人员下拉选择，不允许自由输入。
14. 创建人之前增加“发票类型”，必填下拉，选项为专票、普票、电子票。
15. “统一社会信用代码”之前增加“结算币别”，选择供应商后自动带出，默认 CNY，不允许手工修改。
16. “发票类型”之前增加“付款方式”，必填下拉，选项沿用采购订单口径：电汇、承兑。
17. 支出合同列表在合同负责人之前增加“合同类型”，查询条件同步增加“合同类型”。
18. 未选择供应商时，收款账户下拉无可选数据且不可选择，收款银行为空；选择供应商后加载该供应商的收款账户并默认其中一个。

### 2.2 AI 补充内容与假设

1. 页面采用列表、新增、编辑、查看共用一个 HTML 的列表详情一体结构。
2. 无流程记录点击合同编号默认进入编辑视图；无编辑权限时进入只读查看视图。
3. 状态与业务状态为两个独立维度：状态为草稿、待审核、已审核；业务状态为未生效、履约中、已完结、已终止。本期不增加状态流转动作。
4. 详情仅只读展示状态，不展示业务状态；列表和查询同时展示两个状态维度。
5. 合同不直接生成应付、付款台账或财务凭证，不执行预算占用。
6. 支出合同被采购订单引用后不得删除，避免破坏上下游数据关系；该规则不限制采购订单选择合同。
7. 附件用于保存合同正文、补充协议及相关资料，本期仅提供上传、预览、下载和删除。
8. 列表固定每页 5 条，不提供页容量切换，不在业务内容区产生纵向滚动条。
8. 所属公司由当前公司自动生成且始终只读；支出合同被采购订单引用后，锁定供应商、合同类型、合同日期和标的明细。
9. “供应商快照”是合同历史数据规则；静态原型模拟选择和保存结果，真实持久化由后端实现。

## 3. 业务目标与范围

### 3.1 业务目标

为采购业务提供统一的支出合同录入入口，沉淀签约主体、供应商、合同金额、合同期限、附件及合同标的明细，作为普通采购订单和紧急采购订单的可选关联合同。

### 3.2 主要使用人员

- 合同录入人员：新增、编辑和删除支出合同，维护附件及标的明细。
- 合同负责人：作为合同业务责任人，不承担系统审批或状态维护职责。
- 采购人员：在普通采购订单或紧急采购订单中按实际需要选择支出合同，也可以不选择合同。
- 查看人员：按数据权限查看合同基础信息、附件和标的明细。

### 3.3 本次包含

- 支出合同查询、列表、新增、编辑、查看和删除。
- 合同基础信息、供应商档案选择及供应商信息回填。
- 选填的合同标的明细录入、明细金额计算和合同总金额自动汇总。
- 合同附件上传、预览、下载和删除。
- 普通采购订单和紧急采购订单可选引用支出合同所需的基础数据。

### 3.4 本次不包含

- 项目关联、项目金额分摊和项目预算控制。
- 采购申请关联、采购申请来源追溯及采购申请信息继承。
- 合同审批、会签、审批提交、通过、驳回和审批记录。
- 合同状态流转动作及审批状态。
- 确认完成、终止、续签、变更和版本管理。
- 采购订单明细、入库验收、服务结算、收票、付款及凭证页面。
- 按合同状态、有效期、合同余额限制采购订单关联。
- 合同台账分析、履约进度和预警。

### 3.5 业务链路

```text
采购申请（已审核） -> 普通采购订单 --------> 项目
紧急采购 ----------> 紧急采购订单 --------> 项目
支出合同（可选） ---> 普通 / 紧急采购订单
普通 / 紧急采购订单 -> 入库验收 / 服务结算
                     -> 采购收票 -> 付款申请 -> 财务凭证
```

支出合同只沉淀采购约定，与采购申请无直接关系，是采购订单的可选关联项；支出合同不直接关联项目，不直接形成预算占用、应付数据、付款数据或财务凭证。

## 4. 页面组成与关系

| 视图 | 载体 | 说明 |
| --- | --- | --- |
| 支出合同列表 | 同一 HTML 的列表视图 | 查询、分页、新增、进入合同详情和删除 |
| 新增 | 同一 HTML 的详情视图 | 录入基础信息、附件和合同标的明细 |
| 编辑支出合同 | 同一 HTML 的详情视图 | 修改现有合同信息 |
| 查看支出合同 | 同一 HTML 的只读详情视图 | 无编辑权限时查看全部合同信息 |
| 供应商选择 | 数据选择弹窗 | 从供应商档案单选供应商并回填信息 |
| 附件预览 | 预览弹窗或浏览器预览 | 预览支持的合同附件 |

页面关系：

- 菜单“采购管理 / 支出合同”绑定支出合同列表。
- 点击“新增”在当前 HTML 内切换到新增视图。
- 点击合同编号：有编辑权限时进入编辑视图，无编辑权限时进入只读查看视图。
- 返回列表时保留查询条件、当前页码和表格滚动位置。
- 不设置流程入口、审批面板和审批记录页签。

## 5. 页面区域

### 5.1 列表视图

1. 页面标题：支出合同。
2. 查询区域：合同编号或名称、状态、业务状态、合同类型、供应商、合同负责人和签订日期七个查询条件。
3. 页面操作区：新增、批量删除位于页面标题右上角。
4. 数据列表：展示合同编号、名称、状态、供应商、合同类型、负责人、合同日期及创建审计信息。
5. 分页区域：显示总记录数、总页数、当前页和固定“5 条/页”。

### 5.2 详情视图

1. 详情页头：返回列表及与权限匹配的提交操作。
2. 基础信息页签：先展示合同主体、供应商、合同金额、期限、负责人和审计信息，再在同一页签内展示标的明细表。
3. 附件页签：上传、预览、下载和删除合同资料；无标的明细时至少上传一份附件。
   附件上传区和附件列表直接复用采购申请的公共 `ProUploadList` 样式，不设置页面专用紧凑样式。
4. 合同总金额在基础信息中只读展示，并随标的明细金额变化实时更新，不设置重复金额汇总卡片。

## 7. 操作定义

## 8. 状态与权限

**状态说明：**

本页面将状态和业务状态分开管理。状态为草稿、待审核、已审核；业务状态为未生效、履约中、已完结、已终止。本期不增加状态维护动作。

详情仅展示状态，不展示业务状态；列表与查询同时展示两个状态维度。

签订日期、生效日期和截止日期仅作为合同信息记录及查询条件，不自动生成合同状态，不限制采购订单关联。

**权限矩阵：**

| 权限 | 列表 | 详情 | 可执行操作 |
| --- | --- | --- | --- |
| 查看权限 | 可见授权范围合同 | 全部字段只读 | 查询、查看、附件预览和下载 |
| 新增权限 | 可见新增按钮 | 可录入全部业务字段 | 新增、提交、取消 |
| 编辑权限 | 草稿合同编号进入编辑，待审核和已审核进入只读详情 | 草稿且未被采购订单引用时可完整修改；被引用后仅可修改合同负责人、备注和新增附件 | 提交、取消、按引用情况维护附件 |
| 删除权限 | 每行显示删除操作，仅草稿可用 | 不适用 | 删除未被采购订单引用的草稿合同 |

数据权限按所属公司及用户授权范围过滤；所属公司由当前公司自动生成，本期不新增跨公司授权规则。

## 9. 业务规则与校验

| 编号 | 触发时机 | 条件 | 处理结果 | 提示文案 |
| --- | --- | --- | --- | --- |
| R01 | 选择供应商 | 从供应商档案确认一条记录 | 回填供应商编码、名称、结算币别、统一社会信用代码，刷新账户选项并默认选择首个账户，自动带出收款银行；币别缺失时默认 CNY | 不适用 |
| R02 | 提交 | 未选择供应商 | 阻止提交并定位基础信息 | 请选择供应商 |
| R03 | 提交 | 无合同标的明细且无合同附件 | 阻止提交并切换至附件页签 | 未录入合同标的明细时，请至少上传一份合同附件 |
| R04 | 输入数量 | 数量小于等于 0 | 标记当前单元格错误并阻止保存 | 数量必须大于 0 |
| R05 | 输入含税单价 | 含税单价小于 0 | 标记当前单元格错误并阻止保存 | 含税单价不能小于 0 |
| R06 | 修改数量或含税单价 | 当前行数据有效 | 实时计算明细金额，并汇总更新只读的合同总金额 | 不适用 |
| R07 | 新增或编辑 | 合同总金额字段 | 只读展示，不允许用户手工输入或覆盖 | 合同总金额由标的明细自动计算 |
| R08 | 提交 | 截止日期早于生效日期 | 阻止提交并定位日期字段 | 截止日期不能早于生效日期 |
| R09 | 更换供应商 | 已选择其他供应商 | 清空原回填信息并回填新供应商信息 | 不适用 |
| R10 | 删除合同 | 合同已被采购订单引用 | 阻止删除 | 当前合同已被采购订单引用，不能删除 |
| R11 | 批量删除 | 勾选记录中存在被采购订单引用的合同 | 整批不执行，并列出不可删除合同编号 | 所选合同中存在已被采购订单引用的记录，请调整后重试 |
| R12 | 采购订单关联 | 普通或紧急采购订单选择支出合同 | 合同为可选项；允许不选择；选择时不按状态、有效期或剩余金额过滤 | 不适用 |
| R13 | 提交 | 合同编号、合同名称、合同类型、供应商、日期、负责人、付款方式或发票类型缺失 | 阻止提交并定位第一个错误字段 | 请完善必填信息 |
| R14 | 离开详情 | 存在未保存修改 | 弹出二次确认 | 当前修改尚未保存，确认离开吗？ |
| R15 | 进入编辑 | 合同已被任一采购订单引用 | 供应商、合同类型、签订日期、生效日期、截止日期和全部标的明细只读 | 当前合同已被采购订单引用，核心合同信息不能修改 |
| R16 | 删除已有附件 | 合同已被任一采购订单引用 | 阻止删除，保留原有存档；允许新增补充附件 | 当前合同已被采购订单引用，已有附件不能删除 |
| R17 | 输入合同编号 | 新增合同 | 由用户手工输入，不执行系统自动编号 | 不适用 |
| R18 | 供应商档案变化 | 合同已经保存 | 历史合同继续展示保存时的供应商快照，不自动同步最新档案 | 不适用 |

金额计算采用“数量 × 含税单价”，明细逐行保留 2 位小数后再汇总；合同总金额始终等于当前全部标的明细行金额之和。

## 10. 关键交互

1. 查询和重置只刷新列表结果，不显示演示 Toast。
2. 列表固定每页 5 条，不提供页容量选项，业务内容区不出现纵向滚动条。
3. 点击合同编号在同一 HTML 内进入编辑或只读查看，返回后保留列表上下文。
4. 供应商弹窗为单选；未选择记录时“确认选择”禁用，确认后回填供应商字段、刷新收款账户选项并默认选择首个账户。
5. 收款账户支持在当前供应商的账户范围内下拉选择；账户变化后自动更新只读收款银行。
6. 基础信息和标的明细位于同一页签；标的明细整体选填，支持新增、删除和行内编辑。
7. 数量或含税单价变化后，实时计算当前行金额，并同步更新基础信息中的只读合同总金额。
8. 基础信息或标的明细存在校验错误时定位到基础信息页签，附件存在校验错误时切换到附件页签。
9. 附件支持上传、预览、下载和删除；合同被采购订单引用后只允许新增补充附件，已有附件隐藏删除操作；只读查看模式隐藏上传与删除操作。
10. 提交期间按钮进入加载状态并禁止重复点击；提交成功后保存合同、返回列表并刷新当前记录，不发起审批流程。
11. 删除合同、删除明细、删除附件和放弃未保存修改均执行二次确认。
12. 页面支持直接打开及嵌入 `index.html` 的 iframe，不新增重复菜单标签。
13. 加载中显示骨架或加载状态；列表、明细和附件无数据时分别显示统一空状态；供应商加载失败时提供重试入口。

## 11. 业财关联

### 11.1 归集维度

- 所属公司：支出合同的采购方和签约主体，由当前公司自动生成。
- 供应商：来源于供应商档案，是合同相对方。
- 合同负责人：合同业务责任人。
- 项目：支出合同不维护项目；由后续采购订单关联项目。
- 合同总金额：由标的明细行金额自动汇总，是合同约定金额的页面展示口径。

### 11.2 上下游关系

- 上游主数据：供应商档案、组织人员、公司主体和数据字典。
- 当前单据：支出合同。
- 与采购申请关系：无直接关系，不从采购申请生成，不继承采购申请或项目信息。
- 下游单据：普通采购订单或紧急采购订单，均为可选关联合同。
- 后续链路：采购订单负责关联项目，并继续进入入库验收或服务结算、采购收票、付款申请和财务凭证。

### 11.3 财务影响

支出合同的合同总金额由标的明细行金额自动汇总。支出合同不直接形成应付金额、付款金额或财务凭证，后续采购订单、验收或结算及付款单据负责形成真实业务与财务数据。
