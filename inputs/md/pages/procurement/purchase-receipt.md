## 2. 需求理解与 AI 假设

### 2.1 用户明确要求

1. 采购入库本期暂不考虑价格，不展示和处理单价、币种、金额、税额等价格相关数据。
2. 基础信息字段及顺序为：入库单号、状态、类型、入库日期、供应商、库存地点、创建人、创建时间、审核人、审核时间、所属公司、备注。
3. 类型新增时默认显示“请选择”，不预选蓝字或红字。
4. 蓝字入口和弹窗标题统一为“选择采购订单”，入库明细区域在选择按钮上方显示“入库明细”标题。
22. 新增页面类型尚未选择时，默认显示“选择采购订单”按钮；未补齐类型、供应商和库存地点前按钮保持禁用，选择红字后切换为红字来源按钮。
23. 入库明细去掉“项目”字段；来源选择弹窗仍保留项目查询条件和列表字段。
5. 入库行不显示支出合同及任何价格相关字段。
6. 入库行数量字段仅保留订单数量、可入库数量、入库数量；入库数量默认等于当前未入库数量并支持修改。
7. 蓝字、红字入库明细不显示供应商名称；项目字段按第 23 条最新变更取消展示，采购订单、订单行排列在操作列之前。
8. 采购订单来源通过明细弹窗选择采购订单行，不再先选择订单表头。
9. 反审核成功后采购入库状态直接变为草稿。
12. 采购入库状态为草稿、待审核、已审核。
17. 草稿状态允许维护基础信息、入库行和附件；待审核、已审核状态所有字段和修改类操作均只读或禁用。
18. 采购入库行的来源行按类型显示：蓝字为“订单行”，红字为“入库行”。
19. 选择采购订单弹窗将查询条件和列表字段中的“供应商”改为“项目”。
20. 红字选择蓝字入库行弹窗将查询条件和列表字段中的“供应商”改为“项目”。
21. 采购入库行的来源列按类型动态命名：蓝字显示“采购订单、订单行”，红字显示“蓝字入库单、入库行”。
13. “入库状态”统一更名为“状态”，并紧跟入库单号；“类型”紧跟状态，选项为蓝字、红字。该字段顺序纳入项目公共策略引擎。
14. 入库信息与入库行合并到“基础信息”页签；详情仅保留“基础信息、附件”，删除“关联单据”页签。
15. 蓝字入库选择当前供应商下可入库的采购订单行；红字入库只能选择当前供应商已审核、未关闭且仍有可冲销数量的蓝字入库行。
16. 审核成功时按当前审核操作人和系统时间写入审核人、审核时间；反审核成功后两个字段立即清空，再次审核时重新赋值。

### 2.2 AI 补充内容与假设

1. 用户必须先选择供应商，再打开来源明细弹窗；未选供应商时选择按钮禁用。
2. 弹窗只展示当前公司、当前供应商下，状态为“已审核”、未终止且可入库数量大于 0 的采购订单行。
3. `可入库数量 = 订单数量 - 其他已入库单据累计入库数量`；累计已入库数量参与后台计算，但不作为页面字段展示。
4. 入库数量默认等于可入库数量，用户可在草稿中改小；入库数量必须大于 0 且不得超过最新可入库数量。
5. 供应商为整单字段，一张采购入库单只能选择同一供应商的来源行；项目归属随来源订单行在后台保留但不在入库明细展示，允许同一供应商下跨项目、跨采购订单选择。
6. 库存地点为整单必填字段；明细库位从所选库存地点的有效库位中选择，并优先默认 `A-10-1001`。
7. 修改供应商时，如已存在入库行，二次确认后清空全部明细，避免保留其他供应商数据。
8. 修改库存地点时，如已存在入库行，重新校验所有明细库位；`A-10-1001` 在新库存地点有效时统一重置为该默认库位，否则清空并要求重新选择。
9. 审核与反审核是业务确认动作，不设置审批意见、多级审批流程、流程图或审核记录页签；基础信息仅展示最后一次有效审核的审核人与审核时间，不展示反审核人和反审核时间。
12. 本页面不处理质检、退货、出库、库存计价和会计凭证。
13. 采购入库编号暂按 `GR+YYYYMMDD+3位序号` 生成，属于 AI 假设。

## 3. 业务目标与范围

### 3.1 业务目标

以供应商和库存地点为整单控制维度，从多个采购订单中直接选择可入库订单行，支持同一采购订单分批入库，准确控制订单数量、可入库数量和本次入库数量；项目归属随来源关系在后台保留，不作为入库明细展示字段。

### 3.2 主要使用人员

- 采购或仓储录入人员：选择供应商、库存地点和采购订单，维护入库数量、库位和附件。
- 入库审核人员：审核待审核单据，并对已审核单据执行反审核。
- 业务查看人员：查询供应商、库存地点、采购订单与分次入库记录。

### 3.3 本次包含

- 采购入库列表查询、分页、新增、草稿编辑、查看、删除和批量删除。
- 基础信息供应商、库存地点维护。
- 按供应商筛选并多选采购订单行。
- 一张采购入库单可关联该供应商的多张采购订单和多个项目明细。
- 同一采购订单行按可入库数量分多次入库。
- 订单数量、可入库数量、入库数量和库位维护。
- 草稿提交、待审核审核和已审核反审核。
- 附件上传、预览和下载。

### 3.4 本次不包含

- 单价、币种、含税或不含税金额、税率、税额及任何金额汇总、金额校验。
- 支出合同字段及合同穿透。
- 采购订单审批、变更、终止和合同维护。
- 到货质检、不合格品处理、独立采购退货单据。
- 采购服务结算；本页面仅处理可入库的物资或资产类订单明细。
- 库存地点、库位、供应商和项目主数据维护。
- 库存出库、调拨、盘点、库存成本计价和会计凭证生成。
- 超收容差、赠品入库和无订单入库。

### 3.5 业务链路

```text
供应商 + 库存地点
  -> 选择已审核采购订单行（可多订单、可多项目、可分批）
  -> 采购入库草稿
  -> 待审核
  -> 审核 / 已审核
  -> 采购收票
  -> 付款申请 / 付款核销
```

## 4. 页面组成与关系

| 视图 | 载体 | 说明 |
| --- | --- | --- |
| 采购入库列表 | 同一 HTML | 查询、分页、新增、批量删除及进入详情 |
| 新增 | 同一 HTML 的详情视图 | 选择供应商、库存地点和采购订单 |
| 编辑采购入库 | 同一 HTML 的详情视图 | 草稿状态修改基础信息、入库行和附件 |
| 查看采购入库 | 同一 HTML 的详情视图 | 待审核、已审核状态只读查看，所有字段和修改操作禁用 |
| 选择采购订单 | 多选弹窗 | 按基础信息供应商筛选可入库订单明细，支持跨订单、跨项目多选 |
| 附件 | 详情页签 | 维护送货单、签收单、到货照片等入库资料 |

页面关系：

- 点击菜单进入采购入库列表；新增、编辑和查看在同一 HTML 内切换。
- 点击入库单号：草稿进入编辑视图，待审核和已审核进入全字段只读查看视图。
- 草稿必须先选择供应商和库存地点，再从弹窗多选该供应商的采购订单行。
- 同一采购订单行未全部入库前，可继续被其他采购入库单选择；弹窗按最新已入库结果计算可入库数量。
- 反审核成功后直接进入草稿编辑视图，原入库行保留，可修改后重新提交。
- 返回列表时保留查询条件、页码和滚动上下文，不新增重复菜单标签。

## 5. 页面区域

### 5.1 列表视图

1. 页面标题：采购入库；右侧显示批量删除、审核、反审核和新增。审核、反审核必须单选列表单据后按状态启用。
2. 查询区域：展示入库单号、状态、类型、供应商、库存地点、入库日期和采购订单号，不保留重复的供应商查询项。
3. 采购入库列表：展示状态、类型、入库日期、供应商、库存地点和创建人；不展示项目、订单数量、汇总数量或价格金额字段。
4. 分页区域：显示总记录数、固定“5条/页”和页码，不提供页容量选择。

### 5.2 详情视图

1. 详情页头：仅显示返回列表，以及草稿状态下的保存草稿、提交；审核、反审核不放在详情页。
2. 基础信息页签：表单字段顺序为入库单号、状态、类型、入库日期、供应商、库存地点、创建人、创建时间、审核人、审核时间、所属公司、备注；同一页签下方显示标题“入库明细”。
3. 入库明细：类型未选择或为蓝字时显示“选择采购订单”，红字显示“选择蓝字入库行”；类型未选择时按钮可见但禁用，切换类型必须清空已选来源明细，防止来源类型混用；表格底部实时合计入库数量。
4. 附件页签：上传和查看送货单、签收单、到货照片等资料；页签内容不重复显示“附件”标题。
6. 审核确认弹窗：说明审核后状态变为已审核，并写入审核人、审核时间。

### 6.5 附件或其他字段

附件页签直接展示上传区域和附件列表，不重复显示“入库附件”等内部标题。附件为选填，可保存送货单、签收单、到货照片等资料。草稿状态支持上传、预览、下载和删除；待审核、已审核状态仅支持预览和下载。附件列表仅展示文件名、大小、上传人、上传时间、操作，不展示资料类型。


选择采购订单弹窗：

| 类型 | 字段或规则 |
| --- | --- |
| 固定上下文 | 当前供应商、当前公司，只读展示 |
| 查询字段 | 采购订单号、项目、采购类别、采购名称 |
| 列表字段 | 订单日期、采购类别、采购名称、规格、单位、订单数量、可入库数量、项目、采购订单、订单行 |
| 选择方式 | 方形复选框多选；只允许选择可入库数量大于 0 的订单行 |
| 数据范围 | 当前公司、当前供应商、采购订单状态为已审核、订单未终止 |
| 回填结果 | 按采购订单和订单行去重带入入库行，入库数量默认等于可入库数量，库位默认 `A-10-1001` |

蓝字入库行选择弹窗：

| 类型 | 字段或规则 |
| --- | --- |
| 固定上下文 | 当前供应商、当前公司，只读展示 |

| 回填结果 | 按蓝字入库单和入库行去重带入红字入库行，红字数量不得超过可退货数量 |

## 9. 业务规则与校验

| 编号 | 触发时机 | 条件 | 处理结果 | 提示文案 |
| --- | --- | --- | --- | --- |
| R01 | 打开明细弹窗 | 未选择供应商 | 禁用选择按钮或阻止打开 | 请先选择供应商 |
| R02 | 打开明细弹窗 | 未选择库存地点 | 禁用选择按钮或阻止打开 | 请先选择库存地点 |
| R03 | 加载明细弹窗 | 采购订单不属于当前公司或当前供应商、状态不是已审核、已终止或可入库数量为 0 | 不进入可选数据源 | 仅可选择当前供应商已审核且可入库的采购订单行 |
| R04 | 确认明细选择 | 当前草稿已存在相同采购订单号和采购订单行 | 不重复新增，保留原明细 | 当前采购订单行已在本入库单中 |
| R05 | 导入明细 | 来源明细可入库数量大于 0 | 入库数量默认等于可入库数量；库位默认 `A-10-1001` | 不适用 |
| R06 | 输入入库数量 | 数量小于等于 0 | 标记当前单元格错误并阻止保存或提交 | 入库数量必须大于 0 |
| R07 | 输入入库数量 | 数量大于当前可入库数量 | 标记当前单元格错误并阻止保存或提交 | 入库数量不能超过可入库数量 |
| R08 | 保存草稿或提交 | 任一明细库位为空 | 阻止操作并定位明细 | 请选择第 N 行库位 |
| R09 | 初始化库位 | `A-10-1001` 属于所选库存地点且有效 | 自动回填默认库位 | 不适用 |
| R10 | 初始化或校验库位 | `A-10-1001` 不属于所选库存地点、已停用或用户无权使用 | 库位保持为空并要求选择其他有效库位 | 默认库位 A-10-1001 当前不可用，请重新选择 |
| R11 | 修改供应商 | 当前草稿已存在明细 | 二次确认；确认后清空全部明细，取消则恢复原供应商 | 修改供应商后将清空已选采购订单行，是否继续？ |
| R12 | 修改库存地点 | 当前草稿已存在明细 | 二次确认；确认后按新库存地点重置或清空全部库位，取消则恢复原库存地点 | 修改库存地点后将重新设置明细库位，是否继续？ |
| R13 | 保存草稿或提交 | 类型、供应商、库存地点、入库日期缺失 | 阻止操作并定位第一个错误字段 | 请完善采购入库基础信息 |
| R14 | 保存草稿或提交 | 没有入库行 | 阻止操作并定位至基础信息页签的入库明细区 | 蓝字请选择采购订单；红字请选择蓝字入库行 |
| R15 | 提交 | 入库日期晚于当前日期 | 阻止提交 | 入库日期不能晚于当前日期 |
| R16 | 提交 | 校验通过 | 状态由草稿变为待审核，所有字段和维护操作转为只读 | 采购入库已提交 |
| R17 | 审核 | 当前状态不是待审核 | 禁止执行 | 仅待审核单据可以审核 |
| R18 | 确认审核 | 任一来源采购订单不再是已审核状态或供应商与基础信息不一致 | 整单审核失败，不更新任何业务数据 | 来源采购订单状态或供应商已变化，请刷新后重试 |
| R19 | 确认审核 | 并发入库导致任一明细入库数量大于最新可入库数量 | 整单审核失败并展示冲突明细 | 采购订单可入库数量已变化，请刷新后重试 |
| R20 | 审核成功 | 全部校验通过 | 在同一事务中更新采购入库状态和采购订单已入库数量；任一步失败则全部回滚 | 不适用 |
| R23 | 反审核 | 当前状态不是已审核 | 禁止执行 | 仅已审核单据可以反审核 |
| R24 | 确认反审核 | 状态为已审核 | 在同一事务中恢复采购订单可入库数量，并将采购入库状态直接改为草稿 | 不适用 |
| R28 | 删除入库单 | 状态不是草稿 | 禁用删除 | 仅草稿采购入库单可以删除 |
| R29 | 批量删除 | 选中项包含非草稿记录 | 整批不执行 | 仅草稿采购入库单可以批量删除 |
| R30 | 删除草稿或删除明细 | 草稿未审核 | 仅删除当前草稿数据，不改变采购订单已入库数量 | 不适用 |

| R34 | 审核成功 | 状态为待审核 | 写入当前审核操作人和系统审核时间 | 覆盖历史已清空的审核信息 |

不适用规则：本期不允许超收，不设置超收容差；不支持无采购订单入库；不展示或校验任何价格、币种、金额、税额；不在采购入库环节生成财务凭证。

## 10. 关键交互

1. 查询和重置只刷新当前列表，不显示演示 Toast；重置后回到第 1 页。
2. 列表固定每页 5 条，不提供其他页容量选项，不产生业务区纵向滚动条。
3. 左侧复选框、入库单号和最右操作列固定；宽表仅在表格区域内部横向滚动。
4. 点击新增进入空白入库单，仅初始化草稿状态、入库日期、所属公司、创建人和创建时间；类型显示“请选择”，供应商、库存地点和明细为空。
5. 用户先选择供应商和库存地点，再打开选择采购订单弹窗；弹窗直接显示当前供应商的可入库订单行，不设置订单表头选择步骤。
6. 弹窗支持同一供应商下跨采购订单、跨项目多选订单行；未选择行时确认按钮禁用，取消弹窗不修改当前草稿。
7. 确认选择时按采购订单号和采购订单行去重；带入后入库数量默认等于可入库数量，库位优先默认 `A-10-1001`。
8. 入库明细列顺序固定为采购业务字段、三个数量字段、库位、备注、来源单据、来源行、操作；不显示项目，来源字段随类型显示为“采购订单、订单行”或“蓝字入库单、入库行”，并紧邻操作列之前。
9. 保存草稿和提交时重新读取来源订单状态、供应商、项目及可入库数量；审核时再次执行服务端并发校验。
10. 仅草稿可编辑和删除；待审核、已审核详情所有表单字段、明细选择、明细勾选与删除、附件上传和删除均不可修改，空值不显示录入提示。
11. 保存、提交、审核和反审核执行期间按钮进入加载状态并禁止重复点击；失败时保持原状态及数据，不产生部分更新。

## 11. 业财关联

### 11.1 归集维度

- 所属公司：采购入库所属公司主体，采购订单弹窗只加载当前公司数据。
- 供应商：基础信息必填，整张入库单只归属一个供应商，所有来源订单明细必须与该供应商一致。
- 项目：明细级归集维度，由采购订单行带入，允许同一供应商下跨项目选择。
- 库存地点：基础信息必填，整张入库单只使用一个库存地点。
- 库位：明细级实物归集维度，来源于基础信息所选库存地点，优先默认 `A-10-1001`。

### 11.2 上下游关系

- 上游来源：当前供应商下，一张或多张已审核采购订单的可入库订单行。
- 当前单据：采购入库。

### 11.3 财务影响

采购入库审核仅确认入库业务事实并更新采购订单已入库数量；反审核同步恢复采购订单可入库数量。本页面不生成财务凭证。

## 13. 样例数据

1. 默认准备 12 条高质量采购入库样例，列表固定每页 5 条。
2. 覆盖草稿、待审核、已审核三种状态，每种状态至少一条可见数据。
3. 至少包含一张入库单选择单个订单行、多张订单行、不同项目订单行，以及同一订单行分两次入库四种场景。
4. 所有入库行必须与基础信息供应商一致，并使用同一基础信息库存地点；项目由来源订单行带入。
5. 入库行覆盖原材料、办公用品和固定资产；库位默认显示 `A-10-1001`，并至少包含一条草稿修改为其他有效库位的样例。
6. 至少一条已审核样例可反审核并回草稿，验证订单可入库数量同步恢复。
7. 至少一条订单行只完成部分入库并仍可继续选择；至少一条订单行已全部入库且不再进入弹窗可选范围。
8. 所有样例满足订单数量、可入库数量和入库数量关系；页面和样例数据均不出现价格、币种、金额或税额字段。
9. 编号、日期和时间符合项目格式，采购订单号与采购订单行能够穿透对应来源数据。
