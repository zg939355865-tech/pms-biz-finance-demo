# 固资变更页面蓝图

## 1. 页面元信息

| 项目 | 内容 |
|---|---|
| 页面名称 | 固资变更 |
| 页面编码 | `fixed-asset-return`（沿用既有路由编码） |
| 所属模块 | 固资管理 |
| 菜单路径 | 固资管理 / 固资变更 |
| 页面类型 | 列表 + 详情一体页 |
| 原型输出 | `pages/fixed-asset/fixed-asset-return.html` |
| Schema | `schemas/pages/fixed-asset/fixed-asset-return.json` |
| 资源基线 | `pms-resource-center-v1` |

## 2. 业务目标与范围

1. 从固定资产台账中单选一张资产卡片，形成一张固资变更单。
2. 固化“变更前”快照，并将其复制为“变更后”初始值；用户只在“变更后”修改允许调整的字段。
3. 单据状态为“草稿、待审核、已审核”。草稿可编辑，提交进入待审核；待审核可审核；已审核可反审核。
4. 审核通过后，按“变更后”信息更新原固定资产卡片，不新增资产卡片，不恢复或增加即时库存。
5. 本次沿用既有页面文件和路由，仅将业务语义由“固资退还”升级为“固资变更”。

## 3. 页面结构

### 3.1 列表页

- 页头标题：固资变更。
- 页头操作：审核、反审核、新增。
- 查询区：固定 3 列布局，支持展开/收起，按钮为查询、重置。
- 列表：固定每页 5 条，不显示页容量下拉，不产生业务页内纵向滚动。
- 单号链接：草稿进入可编辑详情；待审核、已审核进入只读详情。

### 3.2 详情页

- 页头操作：返回列表、保存草稿、提交；不再显示“选择固资台账”。
- 详情仅保留“基础信息”页签，页签内容按“基础信息、变更前、变更后”自上而下纵向排列。
- 固定资产 SN 字段使用带“选择”按钮的选择器，点击后打开固资台账弹窗。
- 基础信息承载单据与审计字段；其下依次展示只读的变更前信息、可按权限编辑的变更后信息。
- 待审核、已审核详情全部只读，且不允许重新选择固资台账。

## 6. 详情字段

### 6.1 基础信息

| 顺序 | 字段 | 控件 | 必填 | 编辑规则/联动 |
|---:|---|---|---|---|
| 1 | 固资变更单号 | 输入框 | 是 | 只读，提交后生成，示例前缀 `BG` |
| 2 | 状态 | 下拉框 | 是 | 只读，新增默认草稿 |
| 3 | 变更日期 | 日期 | 是 | 新增默认当前日期 |
| 4 | 固定资产SN | 选择器 | 是 | 输入框只读，点击字段右侧“选择”按钮打开固资台账弹窗单选 |
| 5 | 固定资产台账 | 输入框 | 是 | 只读，根据固定资产SN带出固定资产名称 |
| 6 | 固定资产编码 | 输入框 | 是 | 只读，根据固定资产SN带出 |
| 7 | 变更原因 | 输入框 | 是 | 草稿可编辑 |
| 8 | 创建人 | 输入框 | 是 | 只读，系统带出 |
| 9 | 创建时间 | 输入框 | 是 | 只读，格式 `YYYY-MM-DD HH:mm:ss` |
| 10 | 审核人 | 输入框 | 否 | 只读，审核后写入，反审核清空 |
| 11 | 审核时间 | 输入框 | 否 | 只读，审核后写入，反审核清空 |
| 12 | 所属公司 | 输入框 | 是 | 只读，按当前组织带出 |
| 13 | 备注 | 输入框 | 否 | 草稿可编辑，最多 200 字 |

### 6.2 变更前

变更前位于基础信息表单下方，使用独立分区标题，展示所选固定资产卡片快照。所有字段只读：固定资产SN、状态、转固日期、固定资产名称、固定资产类别、固定资产编码、使用部门、使用人员、项目、购置日期、折旧方法、原值、使用期限（月）、残值率、累计折旧成本、月折旧成本。

### 6.3 变更后

变更后位于变更前下方，使用独立分区标题。默认复制变更前数据，字段范围与变更前一致。

- 始终只读：固定资产SN、转固日期、固定资产编码、购置日期、折旧方法、原值、使用期限（月）、残值率、累计折旧成本、月折旧成本。
- 草稿可编辑：状态、固定资产名称、固定资产类别、使用部门、使用人员、项目；以上可修改字段均先默认显示变更前数据，支持用户调整。
- 待审核、已审核状态下全部只读。

## 7. 选择固资台账弹窗

### 7.1 交互

- 标题：选择固资台账。
- 选择方式：单选，不显示全选。
- 操作：取消、确认选择。
- 确认后回填基础信息、变更前和变更后；变更前为快照，变更后为可编辑副本。
- 重新选择资产时，覆盖当前三块中与资产相关的信息。
- 弹窗允许内部纵向滚动；列表固定每页 5 条。

## 8. 状态与操作规则

| 当前状态 | 允许操作 | 下一状态 | 关键结果 |
|---|---|---|---|
| 草稿 | 保存草稿、编辑、删除、提交 | 待审核 | 校验必填字段并锁定待审核版本 |
| 待审核 | 查看、审核 | 已审核 | 写入审核人/审核时间，并按变更后信息更新原资产卡片 |
| 已审核 | 查看、反审核 | 草稿 | 清空审核人/审核时间，恢复草稿编辑 |

- 审核仅在单选“待审核”记录时启用。
- 反审核仅在单选“已审核”记录时启用。
- 不允许批量审核或批量反审核。
- 已审核单据发生反审核后，原资产卡片恢复到本单审核前快照；静态原型仅演示状态门禁与字段结果，不宣称已实现生产事务回滚。

## 9. 校验与异常

| 编号 | 场景 | 处理 |
|---|---|---|
| R01 | 未选择固定资产SN即提交 | 阻止提交并提示“请选择固定资产SN” |
| R02 | 变更原因为空 | 阻止提交并定位字段 |
| R03 | 变更后必填字段为空 | 阻止提交并滚动定位到“变更后”字段 |
| R04 | 未选记录执行审核/反审核 | 操作按钮禁用 |
| R05 | 选择状态不符合操作门禁 | 操作按钮禁用 |
| R06 | 审核时原资产版本已变化 | 生产实现应阻止审核并提示重新加载；原型以规则文案表达 |

## 10. 验收要点

- [ ] 菜单及页面标题均为“固资变更”，既有路由可正常打开。
- [ ] 详情仅保留“基础信息”页签，页签内按“基础信息、变更前、变更后”纵向排列。
- [ ] 右上角无“选择固资台账”按钮，固定资产 SN 字段右侧“选择”按钮可打开弹窗。
- [ ] 基础信息 13 个字段、顺序、只读与联动关系准确。
- [ ] 主列表 9 个字段与查询区 6 个字段顺序准确。
- [ ] 选择弹窗查询 5 个字段、列表 6 个字段顺序准确，且为单选。
- [ ] 选择资产后，基础信息、变更前、变更后均正确回填。
- [ ] 变更前只读；变更后仅允许规定字段编辑，全部可修改字段默认显示变更前数据且可实际调整。
- [ ] “保管人、折旧成本归集部门”不在变更前和变更后展示；“购置日期、折旧方法、使用期限（月）、残值率”在变更后只读。
- [ ] 草稿、待审核、已审核示例齐全；审核和反审核状态门禁有效。
- [ ] 主列表固定 5 条/页，无页容量下拉；桌面端无页面级横向溢出。
- [ ] 页面引用原型资源中心，不手工维护生成 HTML。
