## 2. 需求理解与 AI 假设

### 2.1 用户明确要求

1. 在物资管理中增加“其他出库”菜单功能。
2. 其他出库支持从即时库存选择出库物资。
3. 出库必须选择项目、成本归集部门和业务类型；项目新增时默认“通用项目”，并支持编辑。
4. 业务类型固定为：盘亏出库、报废出库、其他出库。

### 2.2 AI 补充内容与假设

1. 复用现有物资出库的单据生命周期：草稿、待审核、已审核；只有审核通过后扣减即时库存。
2. 新增时先维护出库日期、库存地点、项目、成本归集部门和业务类型，再选择即时库存；选择弹窗仅展示所选库存地点下库存余量大于 0 的记录。
3. 项目表示本次损耗或处置的归集项目，新增默认“通用项目”，用户可选择其他项目。
4. 本页面不处理领用退库、红字冲回和跨库存地点调拨；如需撤销，暂按反审核后修改或删除处理。
5. 其他出库属于受控库存调整入口，备注按需维护，业务依据附件保持必填；审批角色、反审核权限、成本计价和凭证规则缺少依据，列入待确认项。

## 3. 业务目标与范围

### 3.1 业务目标

登记盘亏、报废及其他非领用场景的库存减少，明确项目与成本归集部门，保留即时库存记录关联，并形成可审核、可追溯的库存变动事实。

### 3.2 主要使用人员

- 仓储人员：新建、维护并提交其他出库单。
- 业务或项目人员：确认归集项目、成本归集部门及业务说明。
- 审核人员：审核或反审核单据，控制库存影响时点。

### 3.3 本次包含

- 其他出库单查询、分页、新增、编辑、查看、删除。
- 从即时库存选择一条或多条正库存记录。
- 项目、成本归集部门、业务类型必填控制；项目默认通用项目并支持编辑。
- 草稿提交、审核、驳回、反审核和库存扣减。
- 附件上传及库存来源追溯。

### 3.4 本次不包含

- 领用出库、销售出库、调拨出库及红字退库。
- 自动盘点、报废审批专项流程及资产处置流程。
- 库存计价方法、会计科目、税务处理及财务凭证生成。
- 跨公司、跨核算主体出库。

### 3.5 业务链路

```text
即时物资 -> 其他出库草稿 -> 提交待审核 -> 审核通过 -> 即时库存扣减 -> 物资流水
```

## 5. 页面区域

### 5.1 列表视图

1. 面包屑和标题：物资管理 / 其他出库。
2. 查询区域：按出库单号、状态、出库日期、业务类型、成本归集部门、项目顺序展示。
3. 操作区：新增、批量删除；批量删除仅处理草稿。
4. 数据列表：固定每页 5 条，不提供页容量选择，不出现业务页内纵向滚动条。
5. 行操作：查看、编辑、删除、提交、审核、反审核，按状态和权限显示。

### 5.2 详情视图

1. 顶部主操作区：返回、保存草稿、提交审核、审核、驳回、反审核。
2. 基础信息：桌面端三列布局，字段顺序为出库单号、状态、出库日期、业务类型、库存地点、成本归集部门、项目、创建人、创建时间、审核人、审核时间、所属公司、备注；项目默认通用项目并支持编辑。
3. 出库明细：通过“选择即时库存”增加明细；仅出库数量和备注可编辑；表格底部增加合计行，实时合计出库数量。
4. 附件：上传盘点依据、报废证明或其他业务附件，页签名称显示为“附件”。
5. 流程信息：沿用页面右上角工作流入口，不新增详情页签。

## 10. 关键交互

1. 查询、重置后回到第 1 页；列表固定每页 5 条。
2. 新增详情默认处于草稿编辑态，出库日期默认当前日期，经办人自动带出。
3. “选择即时库存”在库存地点为空时禁用；选择后仅回填库存来源字段，不自动填写出库数量。
4. 弹窗支持多选、当前页全选、查询、重置和确认；关闭不保留未确认选择。
5. 项目和成本归集部门使用真实档案选择器；项目新增默认通用项目并支持编辑，项目名称与编码、部门名称与编码同步回填。
6. 业务类型严格使用固定枚举，不允许自由输入。
7. 保存草稿不扣库存；审核通过后刷新即时库存和物资流水。
8. 返回列表保留查询条件和分页上下文；加载、空数据、失败和禁用状态均有明确反馈。
9. 页面可直接打开并支持 iframe 嵌入。

## 11. 业财关联

### 11.1 归集维度

- 核算主体、项目、成本归集部门、业务类型、物资、库存地点、库位、库存来源。

### 11.2 上下游关系

- 上游来源：即时物资记录。
- 当前单据：其他出库单及明细。
- 下游单据：即时物资、物资流水；项目或部门成本归集待财务规则确认。
- 穿透链路：`库存入库来源 -> 即时物资 -> 其他出库明细 -> 物资流水`。

### 11.3 财务影响

审核通过后确认实物库存减少，并保留项目、成本归集部门及业务类型作为成本归集依据。本次不确定库存计价、损失或报废科目、凭证模板及生成时点，因此不声明自动生成财务凭证。
