## 2. 需求理解与 AI 假设

### 2.1 用户明确要求

1. 将物资管理菜单中的“物料领用”更名为“物资出库”。
2. 类型固定为蓝字、红字；蓝字参照即时库存，红字参照蓝字出库单。
3. 截图中“基础信息”区块标题不显示，字段直接展示在“出库信息”页签内。
4. 物资出库支持审核、反审核操作。
5. 出库明细必须按所选库存地点从即时库存中选择。
6. 列表字段固定为：出库单号、状态、类型、出库日期、库存地点、领用部门、项目、创建人、创建时间。
7. 基础信息字段固定为：出库单号、状态、出库日期、类型、库存地点、领用部门、项目、创建人、创建时间、审核人、审核时间、所属公司、备注；项目使用下拉选择并默认通用项目。
8. 选择领用部门后默认显示一个项目，并支持项目调整。
9. 明细字段固定为：采购类别、采购名称、规格、单位、库位、可出库数量、出库数量、备注、物资出库单（蓝字）、出库行、操作。
10. 即时库存选择弹窗字段固定为：采购类别、采购名称、规格、单位、库位、库存余量；以库存余量作为可出库上限；查询条件为采购类别、采购名称。
11. 详情操作支持保存草稿。
12. 状态分为草稿、待审核、已审核。
13. 红字选择弹窗字段固定为：出库日期、采购类别、采购名称、规格、单位、库位、已出库数量、已退货数量（负数）、物资出库单（蓝字）、出库行；查询条件为采购类别、采购名称、物资出库单。
14. 蓝字出库数量为正，红字出库数量为负，出库数量绝对值不得超过可出库数量。
15. 蓝字明细的物资出库单（蓝字）、出库行为空；红字可出库数量等于已出库数量减去已退货数量绝对值。
16. 附件单独设置页签。
17. 查询条件固定为：出库单号、状态、类型、库存地点、领用部门（下拉）、项目、出库日期。

### 2.2 AI 补充内容与假设

1. 采用“表头先行、库存选择在后”的主从单据模式：未选择库存地点时不得打开即时库存选择弹窗。
2. “出库明细”解释为物资出库详情中的明细表，不新增独立菜单页面。
3. 本页面采用非流程审核，不生成审批待办；草稿提交后进入待审核，待审核可审核，已审核可反审核，反审核后回到草稿。
4. **AI 假设：**同一张出库单只允许一个库存地点；即时库存选择范围按库存地点过滤，并仅展示库存余量大于 0 的记录。
5. **AI 假设：**保存草稿和提交待审核均不更新库存，审核蓝字时扣减库存，审核红字时按负数数量冲回库存。
6. **AI 假设：**已审核单据反审核前校验是否已被下游业务或财务数据引用；存在引用时禁止反审核。
7. 选择领用部门后，系统自动带出该部门的默认项目；用户可在该部门关联的可选项目范围内调整。
8. 类型新增时默认为“请选择”；该默认态先显示“选择即时库存”按钮，选择红字后切换为“选择蓝字出库单”。
9. “出库信息”页签只承载基础信息字段和出库明细；附件使用独立“附件”页签。
10. 用户已要求生成页面原型，本轮同步生成正式 Schema、HTML 并更新菜单入口。

## 3. 业务目标与范围

### 3.1 业务目标

建立蓝字出库与红字退回的闭环：蓝字从即时库存选料，红字从原蓝字出库行选料，统一控制数量绝对值并保留来源单号、行号追溯。

### 3.2 主要使用人员

- 仓储人员：新增和维护物资出库单，按类型选择即时库存或蓝字出库行并填写出库数量。
- 仓储审核人员：审核或反审核物资出库单。
- 项目、部门及财务相关人员：查看物资去向、领用对象及后续成本归集依据。

### 3.3 本次包含

- “物料领用”菜单名称变更为“物资出库”的页面蓝图约束。
- 物资出库单查询、列表、新增、编辑、查看和删除。
- 蓝字参照即时库存，红字参照蓝字出库单；两类来源均按库存地点约束。
- 出库数量校验、审核、反审核和库存数量更新规则。
- 出库单、即时库存、原蓝字出库行及红字明细之间的追溯关系。
- 草稿保存和独立附件页签。

### 3.4 本次不包含

- 独立“出库明细”菜单页面。
- 从即时物资列表直接发起出库的快捷入口。
- 调拨、盘点、报废、采购退货等其他库存业务页面。
- 审批流程配置、审批待办和多级审批。
- 出库计价方法、会计科目、凭证生成规则及与财务系统的接口实现。

### 3.5 业务链路

```text
蓝字：即时物资 -> 蓝字物资出库草稿 -> 提交待审核 -> 审核确认 -> 即时库存扣减
红字：已审核蓝字出库行 -> 红字物资出库草稿 -> 提交待审核 -> 审核确认 -> 即时库存冲回
```

## 4. 页面组成与关系

| 视图 | 载体 | 说明 |
| --- | --- | --- |
| 物资出库列表 | 同一 HTML | 查询、分页、进入详情、删除草稿及执行审核/反审核 |
| 新增出库 | 同一 HTML 详情视图 | 先维护基础信息，再按蓝字/红字选择对应来源并录入出库数量 |
| 编辑出库 | 同一 HTML 详情视图 | 草稿状态可编辑基础信息、出库明细和独立附件页签 |
| 查看出库 | 同一 HTML 详情视图 | 待审核、已审核状态只读展示基础信息、出库明细和附件 |
| 即时库存选择 | `ProDataSelectModal` 弹窗 | 按表头库存地点过滤可出库库存，支持多选回填明细 |
| 蓝字出库单选择 | `ProDataSelectModal` 弹窗 | 按表头库存地点过滤已审核蓝字出库行，支持多选回填红字明细 |
| 审核/反审核 | 列表页头单选状态动作 | 选择一条记录后，根据状态启用对应操作 |

页面关系：

- 点击列表中的出库单号进入详情；草稿进入编辑模式，待审核和已审核进入只读模式。
- 点击“新增”进入空白详情；类型默认为“请选择”且先显示“选择即时库存”，蓝字继续显示“选择即时库存”，红字切换为“选择蓝字出库单”。
- 即时库存选择弹窗只返回当前库存地点的可出库记录；确认选择后写入出库明细。
- 详情返回列表时保留原查询条件、当前页和滚动位置。

## 5. 页面区域

### 5.1 列表视图

1. 面包屑与页面标题：展示“物资管理 / 物资出库”和页面名称。
2. 查询区域：按出库单号、状态、类型、库存地点、领用部门（下拉）、项目、出库日期展示；支持查询、重置。
3. 页面操作区：标题右侧展示新增、批量删除、审核、反审核；审核和反审核均依赖单选记录状态。
4. 数据列表：展示出库单核心信息，出库单号作为唯一详情入口，操作列固定在最右侧且只显示删除。
5. 分页区域：固定每页 5 条，不提供页容量选择，不产生业务页内部纵向滚动条。

### 5.2 详情视图

1. 页面标题与主操作区：新增或草稿编辑显示“返回列表、保存草稿、提交”；待审核和已审核查看仅显示“返回列表”。审核、反审核不在详情页重复出现。
2. “出库信息”页签：不显示“基础信息”区块标题，直接展示基础信息字段和出库明细。
3. 基础信息：三列布局，字段顺序固定为出库单号、状态、出库日期、类型、库存地点、领用部门、项目、创建人、创建时间、审核人、审核时间、所属公司、备注。
4. 出库明细：蓝字从即时库存选择，红字从蓝字出库单选择；草稿支持删除选中明细和行删除；表格底部实时合计出库数量。
5. “附件”页签：草稿状态支持上传和删除，待审核、已审核状态只读查看。

## 7. 操作定义

### 7.1 列表操作

| 操作 | 位置 | 可用条件 | 执行结果 | 是否确认 |
| --- | --- | --- | --- | --- |
| 查询 | 查询区 | 始终可用 | 按条件筛选并回到第 1 页 | 否 |
| 重置 | 查询区 | 始终可用 | 清空查询条件并回到第 1 页 | 否 |
| 新增 | 页面标题右侧 | 有新增权限 | 进入空白新增详情 | 否 |
| 批量删除 | 页面标题右侧 | 已选择记录且所选记录均为草稿 | 删除所选草稿并更新列表数量与分页总数 | 是 |
| 审核 | 页面标题右侧 | 单选一条待审核记录且有审核权限 | 二次确认后校验数量并将状态变为已审核；蓝字扣减库存、红字冲回库存 | 是 |
| 反审核 | 页面标题右侧 | 单选一条已审核且有反审核权限、单据未被下游引用 | 二次确认后撤销本单库存影响，状态回到草稿 | 是 |
| 删除 | 行操作 | 当前行是草稿且有删除权限 | 删除当前草稿并更新列表数量与分页总数 | 是 |

### 7.2 详情操作

| 操作 | 位置 | 可用条件 | 执行结果 | 是否确认 |
| --- | --- | --- | --- | --- |
| 返回列表 | 详情页头 | 始终可用 | 返回列表并恢复列表上下文；有未保存修改时提示确认 | 条件确认 |
| 保存草稿 | 详情页头 | 新增或草稿编辑且有维护权限 | 保存当前已录入内容，状态保持草稿并返回列表；不执行完整提交校验 | 否 |
| 提交 | 详情页头 | 新增或草稿编辑且有维护权限 | 完整校验基础信息和明细，状态变为待审核并返回列表 | 否 |

## 8. 状态与权限

| 状态 | 页面只读性 | 可执行操作 | 可编辑内容 | 下一状态 |
| --- | --- | --- | --- | --- |
| 草稿 | 可编辑 | 保存草稿、提交、删除、维护附件 | 基础信息、出库明细、附件 | 草稿或待审核 |
| 待审核 | 只读 | 查看、审核 | 无 | 已审核 |
| 已审核 | 只读 | 查看、反审核 | 无 | 草稿 |

权限补充：

- 查看权限仅允许查询列表和查看详情。
- 维护权限允许新增、编辑、保存草稿、提交、维护附件和删除草稿。
- 审核权限允许审核待审核记录；反审核权限允许对满足条件的已审核单据反审核。
- 审核、反审核统一放在列表页头右侧；详情页关闭重复审核入口和流程入口。
- 页面为非流程业务审核，不生成审批待办，不展示流程动态、当前责任人和流程图。

## 10. 关键交互

1. 查询、重置后回到第 1 页，不显示通用 Toast；列表固定每页 5 条，不提供页容量选择。
2. 业务列表操作列固定在最右侧，横向滚动时背景不透明；出库单号是进入详情的唯一入口。
3. 点击新增进入空白详情，类型默认“请选择”、项目下拉默认通用项目；“出库信息”与“附件”分为两个页签，且不显示“基础信息”区块标题。
4. 类型为“请选择”或蓝字时显示“选择即时库存”，红字显示“选择蓝字出库单”；未选择库存地点时当前来源按钮禁用，弹窗数据在数据源层按库存地点和权限过滤。
5. 即时库存弹窗查询条件仅包含采购类别下拉框和采购名称输入框；列表展示采购类别、采购名称、规格、单位、库位、库存余量，支持多选、查询、重置和分页。
6. 明细较宽时仅明细表区域横向滚动；操作列固定在最右侧，业务页面本身不产生纵向滚动条。
7. 保存草稿允许业务必填项暂不完整；提交执行完整校验并进入待审核；提交和审核时再次读取蓝字库存余量或红字剩余可退数量。
8. 选择领用部门后项目下拉自动带出通用项目，并仅展示该部门关联项目。
9. 审核和反审核在列表页头完成：待审核可审核，已审核可反审核；操作前显示明确确认弹窗，完成后刷新列表状态及即时库存。
10. 草稿支持附件上传、预览、下载和删除；待审核、已审核只允许预览和下载。
11. 详情只读状态下空值显示为空白，不显示录入占位文字；待审核、已审核详情不显示明细及附件维护按钮。
12. 页面加载、弹窗加载使用局部加载态；无可选库存时显示空状态；加载失败保留已填表头并允许重试。
13. 未保存离开详情时提示确认；保存草稿、提交或无修改时返回并恢复列表查询、页码和滚动位置。
14. 页面支持直接打开和 iframe 嵌入；返回或菜单切换遵循父级标签页通信规范。

## 11. 业财关联

### 11.1 归集维度

- 所属公司或核算主体、库存地点、库位、采购类别、采购名称、领用部门、领用项目。

### 11.2 上下游关系

- 上游来源：蓝字为即时库存，红字为已审核蓝字物资出库行。
- 当前单据：物资出库单及出库明细。
- 下游单据：即时物资汇总、物资流水；项目或部门成本归集及财务凭证规则待确认。
- 穿透链路：`物资入库来源 -> 即时库存记录 -> 蓝字出库行 -> 红字出库行 -> 物资流水`。

### 11.3 财务影响

物资出库审核后确认实物库存减少，并为项目或部门成本归集提供业务事实。本次不确定出库计价方法、库存金额、会计科目和凭证生成时点，因此不直接声明生成财务凭证；确认财务口径后再补充金额一致性及凭证穿透规则。
