# 库存地点页面蓝图

## 1. 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面名称 | 库存地点 |
| 页面编码 | `inventory-location` |
| 页面类型 | 主数据列表详情一体页 |
| 菜单路径 | 物资管理 / 库存地点 |
| 输出页面 | `pages/material/inventory-location.html` |

## 2. 本次优化范围

1. 去除“库位信息”独立页签；库位信息表置于“基础信息”表单下方。
2. 查询区仅保留“库存地点编码或名称”。
3. 列表仅显示：库存地点编码、库存地点名称、创建人、创建时间。
4. 基础信息按顺序显示：库存地点编码、库存地点名称、创建人、创建时间、所属公司、备注。
5. 库位信息按顺序显示：库位编码、是否默认库位、备注。

## 3. 页面结构

```text
库存地点
├─ 查询区：库存地点编码或名称
├─ 列表：库存地点编码、库存地点名称、创建人、创建时间
└─ 详情：基础信息（唯一页签）
   ├─ 基础信息表单
   └─ 库位信息可编辑表格
```

## 4. 字段与交互

| 区域 | 字段 | 控件与规则 |
| --- | --- | --- |
| 查询区 | 库存地点编码或名称 | Input，按编码或名称模糊查询 |
| 列表 | 库存地点编码 | Link，点击进入详情 |
| 列表 | 库存地点名称、创建人、创建时间 | Text / Datetime，创建时间格式为 `YYYY-MM-DD HH:mm:ss` |
| 基础信息 | 库存地点编码、创建人、创建时间 | 系统生成，只读 |
| 基础信息 | 库存地点名称 | 必填输入 |
| 基础信息 | 所属公司 | 固定默认“昕彤赋能（武汉）设计研究有限公司”，只读 |
| 基础信息 | 备注 | 可选输入 |
| 库位信息 | 库位编码 | 必填输入；同一库存地点内唯一 |
| 库位信息 | 是否默认库位 | 是/否单选互斥；同一库存地点最多一个“是” |
| 库位信息 | 备注 | 可选输入 |

## 5. 组件与样例映射

- 资源中心：`prototype-resources/index.html`，基线 `pms-resource-center-v1`。
- 组件：`ProSearchForm`、`ProTable`、`ProTabsDetail`、`DetailForm`、`EditableTable`。
- 参考样例：物资出库的库存地点—库位从属关系；差异为本页将库位维护嵌入基础信息页签下方。

## 6. 验收标准

- [ ] 不存在“库位信息”独立页签。
- [ ] 查询、列表、基础信息与库位信息字段严格符合本蓝图的字段和顺序。
