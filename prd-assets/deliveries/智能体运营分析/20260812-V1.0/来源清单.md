# 智能体运营分析 UR V1.0 来源清单

- `inputs/md/pages/report/agent-operation-analysis.md`：页面范围、业务规则、字段、状态和交互的主要依据。
- `schemas/pages/report/agent-operation-analysis.json`：页面组件、字段、操作和校验的结构化依据。
- `pages/project-overview.html`：当前高保真原型及页面行为依据。
- `outputs/reports/visual/agent-operation-analysis*.png`：2026-08-12 重新执行原型检查后生成的当前页面截图。
- `rules/project-standard.md`：项目级页面、权限、状态和交付约束。
- `rules/interaction.md`：查询、表格、弹窗、反馈和异常交互规范。
- `rules/data-standard.md`：日期、数值和字段展示规范。
- `prd-assets/prd-document-standard.md`：PRD/UR 内容与验收规范。
- `inputs/issue/需求变更台账.md`：历史变更及字段冲突识别依据。
- `$mes-ur-generator`：文档结构、格式、图表和生成检查流程。

说明：正式文档以当前蓝图、正式 Schema、当前原型及项目规则为优先依据；无法由现有资料确认的内容均标记为“待确认”。
