# UI 设计标准

## 页面布局
经典后台管理系统布局：左侧固定菜单栏 + 顶部工具栏 + 右侧主内容区

## 页面样式规范
- **默认样式**：白色背景（B端企业管理风格），如无特殊说明，所有页面均使用默认样式
- **大屏样式**：仅在用户明确要求时使用深色背景，如"智能体驾驶舱"等特殊页面
- **区分方式**：大屏页面通常用于数据监控/驾驶舱场景，需要明显视觉区分

## 菜单模式
侧边菜单 + 顶部标签页（支持多标签并行切换）

## 表格规范

### 可编辑明细表标题与工具栏对齐

- `EditableTable` 的区块标题、工具栏首个按钮必须使用相同左内边距和左边界，不得由空占位元素产生额外偏移。
- 工具栏按钮必须在工具栏有效高度内垂直居中；不同缩放比例、空数据和有数据状态下均保持一致。
- 同一详情页连续出现多张可编辑明细表时，各表标题、首个工具栏按钮和表格容器边界必须使用统一对齐规则，不得编写单页私有偏移样式。

### 表格样式
| 项目 | 样式 |
|-----|------|
| 表头背景 | #F8FAFC |
| 表头文字 | #475569，字号14px，字重400 |
| 表头高度 | 56px |
| 表头边框 | 底部 1px #E2E8F0 |
| 表格行高 | 56px |

### 表格对齐规则
| 字段类型 | 对齐方式 |
|---------|---------|
| 编码/单号/项目名称 | 居左 |
| 日期时间 | 居左，格式统一 |
| 金额/数量 | 居右，保留2位小数 |
| 状态 | 居中 |
| 操作按钮 | 居中 |

### 少列列表均衡布局
- 业务主列表的业务字段不超过 6 列时，公共 `ProTable` 自动启用均衡列布局，表头和数据内容居中，避免少量字段被整行拉伸后形成不连续的大块留白。
- 少列均衡布局使用固定表格布局，操作列仍固定在最右侧；页面整体不得出现横向滚动。
- 超过 6 个业务字段的宽表不启用均衡布局，继续按字段类型执行左对齐、右对齐和居中规则，并仅允许表格内部横向滚动。

### 列宽与长文本
- 列宽按字段语义设置，禁止把状态、名称、日期、数值等不同类型字段设置成等宽。
- 推荐宽度：勾选列 48-56px；序号 72px；状态/是否 88-112px；人员 104-136px；数值 96-120px；日期 128-136px；日期时间 160-176px；编码/编号 152-184px；名称 160-220px；普通描述 200-240px；详情/备注 240-320px。
- 常规业务字段建议最大宽度 240px；仅详情、备注、地址等长文本字段允许放宽到 320px。
- 超过列宽的普通文本由公共 `ProTable` 单行省略，鼠标悬停显示完整值；状态标签、操作按钮、行内编辑控件不使用文本省略。
- Schema 可通过 `columns[].width` 覆盖语义默认宽度，通过 `columns[].ellipsis: false` 明确关闭省略；单页不得编写私有截断样式。

## 分页规范
| 项目 | 样式 |
|-----|------|
| 位置 | 表格下方，独立分页栏 |
| 布局 | 左侧总条数 + 固定页容量组件，右侧翻页控件（左右分布） |
| 总条数样式 | 字号14px，颜色#64748B |
| 翻页控件 | 上一页 + 当前页/总页数 + 下一页 |
| 当前页样式 | 蓝色背景（#2563EB），白色文字，圆角4px |
| 翻页按钮样式 | 白色背景，#D1D5DB边框，#1E293B文字，圆角4px |
| 禁用状态 | 按钮opacity: 0.5，禁止点击 |
| 每页条数 | 分页栏左侧必须显示固定页容量组件；业务列表默认显示“5条/页”，仅用于明确规格，不提供其他条数选项 |

业务列表同时存在“主题”和“状态”列时，状态列固定排列在主题列之后。

## 表单规范

### 列表查询区栅格

- 桌面端查询条件按 4 列栅格排列；条件不足 4 个时，查询、重置等操作在同一行靠右收口。
- 条件恰好占满 4 列（或展开条件恰好占满 4 列）时，操作区必须独占下一行、跨满 4 列并靠右对齐；不得出现在下一行左侧。
- 页面不得通过私有定位、空白占位或负边距改变公共查询区的收口规则。

## 描述列表规范

- `Descriptions`、`ProDescriptionList` 必须按“标签—值”成对排列，标签和值保持同行，不得拆分到相邻行或错位显示。
- 桌面端工作台和详情宽区默认每行 3 组，模态框和抽屉默认每行 2 组；Schema 使用 `layoutColumns` 显式声明，取值仅允许 1、2、3。
- 标签列使用浅灰背景和次要文字色，内容列使用主文字色；标签列窄、内容列宽，长核算主体等业务值优先获得展示空间。
- 窄屏统一降为每行 1 组；不得通过页面私有 CSS 改写公共描述列表栅格。
