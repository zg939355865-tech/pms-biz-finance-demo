# 交互规范

## 列表操作规则

### 冻结规则
1. **上下滑动时**：顶部栏必须冻结（不随内容滚动）
2. **左右滑动时**：最左侧复选框和首个编号/编码/单号列、最右操作列必须冻结，冻结区域使用不透明背景遮挡滑动内容
3. **业务主列表**：操作列固定在最右侧且背景不透明，不随表格横向滚动

### 删除规则
- 所有业务维护列表必须显示「操作」列和「删除」操作
- 操作列只保留删除；查看、编辑通过编号、编码或单号链接进入详情
- 有流程状态的单据仅「草稿」行可删除，其他状态显示禁用删除
- 无流程状态的维护列表默认允许删除
- 点击流程单据链接时，草稿进入编辑模式，其他状态进入只读模式；无流程状态记录进入编辑模式
- 只读报表、监控表、选择弹窗及详情子表不自动增加业务删除操作

### 数据选择弹窗
- 单条关联场景使用 `selectionMode: "single"`，表格显示单选控件，不显示全选。
- 未选择数据时“确认选择”禁用；选择一行后启用。
- “取消”只关闭弹窗，不修改主表单；“确认选择”按 `selectionMap` 回填关联字段并关闭弹窗。
- 可选数据必须在数据源层完成状态和组织权限过滤，不能只依赖页面提示。

### 页面整体规则
- 一览页面必须能够看到全部页面内容
- 不支持页面整体左右滑动

## 标签页规则
- 侧边菜单点击后，右侧顶部出现标签页
- 支持多标签并行切换
- 标签页关闭后返回列表页

### 标签页交互细节
| 操作 | 行为 |
|------|------|
| 点击菜单项 | 检查标签是否已存在 → 存在则切换，不存在则新增并切换 |
| 点击已开标签 | 切换 iframe 到对应页面 |
| 点击标签 × | 关闭标签 → 如果关闭的是当前标签，切换到最后一个标签 |
| 关闭限制 | 至少保留1个标签，不可全部关闭 |

### iframe 父子通信
父窗口（index.html）监听 message 事件：
```js
window.addEventListener('message', (event) => {
  if (event.data.type === 'openTab') {
    navigateTo(event.data.page, event.data.name)
  }
})
```

子页面通过 postMessage 通知父窗口：
```js
window.parent.postMessage({ type: 'openTab', page: 'xxx', name: '标题' }, '*')
```

## 业财一体化交互

### 业务-财务穿透交互
- 业务单据列表应显示「凭证状态」列
- 点击「凭证状态」可跳转查看对应财务凭证
- 财务凭证列表应显示「来源单据」字段，点击可跳转业务单据

### 预算控制交互
- 业务发生时实时显示预算剩余可用金额
- 超预算时显示警告提示（橙色标签）
- 预算执行列表显示已用/已审批/可用三列

### 审批流程交互
- 待审批状态显示紫色标签
- 审批通过/驳回后刷新列表状态
- 详情页只保留统一「审核」入口，通过与驳回均在审核面板内完成
- 无流程录入单据不支持草稿暂存，新增和编辑统一显示「返回列表、提交」；提交只保存业务数据并返回列表，不发起审批流程，不生成待审核状态
- 有流程单据按状态显示操作：草稿可保存草稿和提交，待审核可审核，其他状态只读；保存草稿和提交后返回列表
- 审核记录通过页面右上角流程按钮查看，不单独设置审核记录页签；流程动态、当前责任人和流程图保留右上角入口。
- 详情页右上角已提供“流程动态 / 当前责任人 / 流程图”入口时，内容区禁止重复设置“流程动态”“当前责任人”“流程图”Tab。

### 点击反馈
- 项目页面默认禁止点击后显示 Toast，包括查询、重置、刷新、删除、保存、提交、审核和列设置等通用动作。
- 仅当具体实现说明明确要求 Toast 时，页面 Schema 才可设置 `toastEnabled: true` 并配置对应提示内容；不得由公共运行时自动补充。
