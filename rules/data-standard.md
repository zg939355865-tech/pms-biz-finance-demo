# 数据标准

## 列表样例数据
- 默认样例数据：每个真实流程状态至少 1 条，无流程状态时 5 条
- 默认每页显示：**5 条**（与 project-standard.md §6、§86 对齐）
- 分页组件必须显示总条数和页容量选择器（默认"5条/页"）

## 字段规范
- 编码/单号/项目名称类字段：居左显示
- 金额/数量类字段：居右显示，保留2位小数
- 单价字段：居右显示，保留4位小数
- 状态类字段：根据状态类型使用对应颜色标签
- 日期时间字段：居左显示，格式统一

## 表单规范

### 必填字段标识
- 标记方式：必填项标签前加红色 `*`
- 星号颜色：`#EF4444`（红色）
- 选填项：不标注，默认选填
- 示例：`*项目编号`、`项目名称`（必填vs选填）

### 新增页字段规则
| 规则 | 说明 |
|-----|------|
| 所有字段 | 可编辑 |
| 必填标识 | 必填项显示红色星号 |
| 默认值 | 系统自动生成的字段自动填充 |
| 按钮 | 底部显示「保存」「取消」 |

### 编辑页字段规则
| 字段类型 | 展示规则 |
|---------|---------|
| 可编辑字段 | 正常显示输入框 |
| 不可编辑字段 | 显示为只读文本，背景变灰 |
| 特殊禁止修改 | 如「状态」字段只读，需文字说明原因 |

### 详情页字段规则
| 规则 | 说明 |
|-----|------|
| 展示方式 | 全部字段只读，以文本形式展示 |
| 标签样式 | 与编辑页标签一致 |
| 值样式 | 纯文本，如无值显示「-」 |
| 按钮 | 不显示保存/取消，可显示「返回」 |

### 新增页默认值规则
| 字段 | 默认值 | 来源 |
|-----|-------|------|
| 创建人 | 当前登录用户 | 系统获取 |
| 创建时间 | 当前时间（精确到秒） | 系统自动填充 |
| 项目编号 | 系统自动生成（格式：PRJ+年月日+序号） | 规则配置 |

- 以上3个字段均为只读，由系统自动填充
- 需显示为输入框禁用样式（灰色背景）

### 备注字段规则
| 规则 | 说明 |
|-----|------|
| 位置 | 放在表单最后（状态之后） |
| 控件类型 | 单行输入框（input），使用标准表单高度，不跨行 |
| 所有模块 | 备注字段均支持 |
| 选填 | 不标记必填星号 |

## 业财一体化字段规范

### 金额字段规则
| 规则 | 说明 |
|-----|------|
| 精度 | 保留2位小数 |
| 币种 | 默认人民币（CNY），可配置多币种 |
| 正负 | 收入为正，支出/成本为负 |
| 汇总 | 列表页金额列支持小计汇总 |

### 数量与单价字段规则
| 字段类型 | 精度 | 对齐方式 |
|---------|------|---------|
| 数量 | 保留2位小数 | 右对齐 |
| 单价 | 保留4位小数 | 右对齐 |

### 业务-财务映射字段
| 业务模块 | 业务单据 | 财务凭证 |
|---------|---------|---------|
| 合同管理 | 合同金额 | 应收/应付金额 |
| 收入管理 | 开票金额、确认收入 | 应收账款、凭证金额 |
| 采购管理 | 采购金额、入库金额 | 应付账款、凭证金额 |
| 资金管理 | 收款/付款金额 | 银行收付、凭证金额 |

### 凭证状态字段
| 状态 | 含义 | 颜色标签 |
|-----|------|---------|
| 未生成 | 业务单据尚未生成财务凭证 | 待处理（黄色） |
| 已生成 | 业务单据已生成财务凭证 | 已完成（绿色） |
| 异常 | 凭证金额与业务单据金额不一致 | 已取消（红色） |

## 日期时间规范
| 类型 | 格式 | 示例 |

| 日期 | YYYY-MM-DD | 2026-05-06 |
